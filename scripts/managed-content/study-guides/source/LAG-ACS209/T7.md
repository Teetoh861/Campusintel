## Topic 7: Random Variables and Expectation

**What you must know:** what a random variable is; discrete versus continuous; the two conditions for a valid probability distribution and finding a missing probability or constant k; the cumulative distribution function F(x); expected value E(X) and its meaning; E(X²), variance and standard deviation of a random variable; the rules for E(aX + b) and Var(aX + b); expected profit and expected-value decisions in ₦.

### Lesson 7.1: Random variables, discrete and continuous

**Must know**

- **Random variable:** a numerical description of the outcome of an experiment. Put simply, a variable whose values are determined by chance. It is usually written with a capital letter (X); a particular value it takes is written in small letters (x).
- **Discrete random variable:** takes only a finite or countable number of distinct values, usually obtained by **counting** ("how many").
- **Continuous random variable:** can take any value within an interval (for example any value between 2 and 5), so it has an infinite number of possible values, usually obtained by **measuring** ("how much"): time, weight, length, height, temperature.

| Feature | Discrete | Continuous |
|---|---|---|
| Values | Finite or countable (0, 1, 2, ...) | Any value in an interval |
| Obtained by | Counting | Measuring |
| Probability of one exact value | P(X = x) can be above 0 | P(X = c) = 0 always |
| Probabilities found by | Adding P(x) values | Area under the curve over an interval |
| Examples | Customers arriving, defective bulbs, goals, children | Waiting time, weight of rice, height |

**Explain more**

- Decide by asking: "Do I count it or measure it?" The number of customers who arrive at a bank branch in Lekki in one hour, the number of defective bulbs in a carton, goals scored in a match, children in a household, students in a tutorial class and defective phones in a carton of 12 are all **discrete**. You cannot have 2.63 customers.
- The time taken to serve a customer at a fast-food outlet in Surulere, the time a student waits for a shuttle at the UNILAG main gate and the weight of a bag of rice sold in Mile 12 market are all **continuous**. They are measured, and any value in a range is possible (a wait of 4.37 minutes is fine).
- **Trap:** a random variable is **not** "a variable whose value is chosen by the researcher" (chance decides it), **not** "the set of all possible outcomes" (that is the sample space) and **not** "a probability attached to an event". It is the **number** you attach to each outcome. Example: toss a coin twice; the sample space is {HH, HT, TH, TT}; X = number of heads gives X = 2, 1, 1, 0.
- **Why P(X = c) = 0 for a continuous variable:** there are infinitely many possible values in any interval, so any one exact value has probability 0. For a continuous variable probability is the **area** under its probability density curve, and the area above a single point is 0. So the answer is 0, not "the height of the curve at c".

### Lesson 7.2: Probability distributions and the cumulative distribution function

**Must know**

- **Probability distribution** of a discrete random variable: a table, graph or formula listing each value x with its probability P(x) (also written P(X = x) or f(x)).
- **2 conditions for a valid discrete probability distribution:**

1. 0 ≤ P(x) ≤ 1 for every x (each probability lies between 0 and 1 inclusive; no negatives, nothing above 1).
2. ΣP(x) = 1 (all the probabilities add up to exactly 1).

- **Missing probability:** p = 1 − (sum of the known probabilities).
- **Constant k in a formula:** write ΣP(x) = 1 and solve for k.
- **Cumulative distribution function (CDF):** F(x) = P(X ≤ x), the running total of the probabilities up to and including x.
- **Useful CDF results:** P(X = x) = F(x) − F(previous value); P(a < X ≤ b) = F(b) − F(a); P(X > a) = 1 − F(a). The last F value is always 1.

**Explain more**

- **Checking validity.** For X = 1, 2, 3: (0.2, 0.5, 0.3) is valid (each between 0 and 1, sum = 1.0). (0.3, 0.4, 0.4) sums to 1.1, invalid. (0.2, 0.2, 0.2) sums to 0.6, invalid. (0.5, −0.1, 0.6) has a negative probability, invalid even though it sums to 1. Note that it is the **P(x) values** that add to 1, not the x values; and they need not be equal.
- **Worked example (missing value).** x = 1, 2, 3, 4 with P(x) = 0.15, 0.25, p, 0.3. Then p = 1 − (0.15 + 0.25 + 0.3) = 1 − 0.7 = **0.3**. Similarly P(X = 0) = 0.2, P(X = 1) = 0.35, P(X = 2) = k, P(X = 3) = 0.15 gives k = 1 − 0.7 = **0.3**.
- **Worked example (constant k).** P(X = x) = kx for x = 1, 2, 3, 4. ΣP(x) = k(1 + 2 + 3 + 4) = 10k = 1, so **k = 1/10**. The distribution is P(x) = x/10: 0.1, 0.2, 0.3, 0.4.
- **Worked example (CDF).** x = 0, 1, 2, 3 with P(x) = 0.1, 0.3, 0.4, 0.2.

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| P(x) | 0.1 | 0.3 | 0.4 | 0.2 |
| F(x) = P(X ≤ x) | 0.1 | 0.4 | 0.8 | 1.0 |

  F(1) = 0.1 + 0.3 = **0.4** (not 0.3, which is P(X = 1) alone). P(X ≥ 2) = 0.4 + 0.2 = **0.6**, or 1 − F(1) = 1 − 0.4 = 0.6.
- **Going back from F to P.** If F(1) = 0.35 and F(2) = 0.75, then P(X = 2) = 0.75 − 0.35 = **0.4**. If F(0) = 0.2, F(1) = 0.5, F(2) = 0.9, F(3) = 1, then P(1 < X ≤ 3) = F(3) − F(1) = 1 − 0.5 = **0.5** (this is P(X = 2) + P(X = 3) = 0.4 + 0.1).
- **Trap:** F(x) is P(X ≤ x), "less than or **equal** to". P(X > x), P(X ≥ x) and P(X = x) are the swapped options.

### Lesson 7.3: Expected value (the mean of a random variable)

**Must know**

- **Expected value (mathematical expectation):** E(X) = μ = Σx P(x). Multiply each value by its probability and add.
- E(X) is the **population mean** of X (the mean of its probability distribution).
- **Meaning:** the **long-run average** value of X over many repetitions of the experiment. It is not the most likely value (that is the mode), not the value X must take next time, and not the middle value (that is the median). E(X) need not be a value X can actually take.
- **E(X²) = Σx² P(x)** (square each x first, then multiply by P(x)).
- **Expected monetary value (EMV):** expected profit = Σ(profit × probability); a loss enters as a negative amount.
- **Decision rule:** choose the option with the **highest expected profit** (or lowest expected cost).

**Explain more**

- **Worked example.** X = number of phones a shop in Computer Village sells per hour, with x = 0, 1, 2, 3, 4 and P(x) = 0.1, 0.2, 0.3, 0.25, 0.15.

| x | P(x) | x P(x) | x² P(x) |
|---|---|---|---|
| 0 | 0.10 | 0 | 0 |
| 1 | 0.20 | 0.20 | 0.20 |
| 2 | 0.30 | 0.60 | 1.20 |
| 3 | 0.25 | 0.75 | 2.25 |
| 4 | 0.15 | 0.60 | 2.40 |
| Total | 1.00 | 2.15 | 6.05 |

  E(X) = 2.15 phones per hour; E(X²) = 6.05. The shop will not sell 2.15 phones in any one hour, but over many hours it averages 2.15.
- **Bank-style distribution.** x = 0, 1, 2, 3 with P(x) = 0.1, 0.3, 0.4, 0.2: E(X) = 0 + 0.3 + 0.8 + 0.6 = **1.7**; E(X²) = 0 + 0.3 + 1.6 + 1.8 = **3.7**. Do not confuse E(X²) = 3.7 with [E(X)]² = 1.7² = 2.89.
- **Formula distribution.** P(x) = x/10, x = 1 to 4: E(X) = (1×1 + 2×2 + 3×3 + 4×4) ÷ 10 = 30 ÷ 10 = **3**.
- **Fair die.** Each face has probability 1/6. E(X) = (1 + 2 + 3 + 4 + 5 + 6) ÷ 6 = 21 ÷ 6 = **3.5**.
- **Two coin tosses**, X = number of heads: P(0) = 0.25, P(1) = 0.5, P(2) = 0.25. E(X) = 0 + 0.5 + 0.5 = **1**.
- **Demand.** Daily demand for bread at a kiosk in Akoka is 10, 20 or 30 loaves with probabilities 0.2, 0.5, 0.3. E(X) = 2 + 10 + 9 = **21 loaves**.
- **Expected profit (Balogun trader).** Profit ₦50,000 with probability 0.6, loss ₦20,000 with probability 0.4. E = 50,000 × 0.6 + (−20,000) × 0.4 = 30,000 − 8,000 = **₦22,000**.
- **Choosing between projects.** Project A: ₦22,000 (above). Project B: profit ₦40,000 with probability 0.5 or loss ₦30,000 with probability 0.5. E = 20,000 − 15,000 = ₦5,000. Choose **Project A** (₦22,000 against ₦5,000). The common error is forgetting to make the loss negative (giving ₦38,000 or ₦35,000).
- **Insurance.** Premium ₦10,000; payout ₦200,000 with claim probability 0.02. Expected payout = 200,000 × 0.02 = ₦4,000. Expected profit per policy = 10,000 − 4,000 = **₦6,000**.
- **Fun-fair game.** It costs ₦100 to play; a six (probability 1/6) pays ₦300. Expected winnings = 300 × 1/6 = ₦50. Expected gain = 50 − 100 = **−₦50** (the player loses ₦50 per game on average). A game is called **fair** when expected gain is 0.

### Lesson 7.4: Variance and standard deviation of a random variable

**Must know**

- **Variance:** Var(X) = σ² = Σ(x − μ)² P(x) (definition form).
- **Short-cut form (use this):** Var(X) = E(X²) − [E(X)]².
- **Standard deviation:** σ = √Var(X).
- Variance is **never negative** (it is a weighted average of squares). It can be 0 (when X is a constant) or any positive number, such as 0.25 or 16, but never −2.5.
- **Convention:** here the probabilities act as the weights, so there is no division by n or n − 1. (The n versus n − 1 choice belongs to variance of sample data, covered in Measures of Dispersion.)

**Explain more**

- **Steps:** (1) find E(X) = Σx P(x); (2) find E(X²) = Σx² P(x); (3) Var(X) = E(X²) − [E(X)]²; (4) σ = √Var(X).
- **Phones example (Lesson 7.3):** Var(X) = 6.05 − 2.15² = 6.05 − 4.6225 = **1.4275**; σ = √1.4275 = **1.1948** (4 d.p.).
- **Bank-style distribution:** Var(X) = 3.7 − 1.7² = 3.7 − 2.89 = **0.81**; σ = √0.81 = **0.9**. Traps: 0.81 is the variance, not the standard deviation; 3.7 is E(X²), not the variance.
- **P(x) = x/10:** E(X²) = (1 + 8 + 27 + 64) ÷ 10 = 100 ÷ 10 = 10; Var(X) = 10 − 3² = 10 − 9 = **1**.
- **Fair die:** E(X²) = (1 + 4 + 9 + 16 + 25 + 36) ÷ 6 = 91 ÷ 6 = 15.1667; Var(X) = 91/6 − 3.5² = 15.1667 − 12.25 = 35/12 = **2.9167** (4 d.p.); σ = 1.7078. The options 12.25 (that is [E(X)]²), 15.1667 (E(X²)) and 1.7078 (σ) are all traps.
- **Bread demand:** E(X²) = 100 × 0.2 + 400 × 0.5 + 900 × 0.3 = 20 + 200 + 270 = 490; Var(X) = 490 − 21² = 490 − 441 = **49**; σ = 7 loaves.
- The order matters: E(X²) − [E(X)]², never [E(X)]² − E(X²) (that would give a negative number) and never E(X²) − E(X).

### Lesson 7.5: Rules of expectation and variance for aX + b

**Must know**

For constants a and b:

1. E(b) = b (the expected value of a constant is the constant).
2. E(aX) = aE(X).
3. **E(aX + b) = aE(X) + b.**
4. Var(b) = 0 (a constant does not vary).
5. Var(aX) = a²Var(X).
6. **Var(aX + b) = a²Var(X).** Adding or subtracting b does not change the variance.
7. SD(aX + b) = |a| × SD(X).

**Explain more**

- **Why b drops out of the variance:** adding a constant shifts every value and the mean by the same amount, so the spread is unchanged. If ₦500 is added to every value of X, the variance is **unchanged** (not "increased by 500" or "increased by 250,000").
- **Why a is squared:** variance is measured in squared units, so multiplying values by a multiplies the variance by a². A minus sign disappears when squared, so the variance can never become negative.
- **Worked example.** With E(X) = 1.7 and Var(X) = 0.81: E(2X + 3) = 2 × 1.7 + 3 = 3.4 + 3 = **6.4**; Var(2X + 3) = 2² × 0.81 = 4 × 0.81 = **3.24**. Traps: 4.7 (forgot to multiply by 2), 3.4 (forgot to add 3), 1.62 (used a instead of a²), 6.24 (added 3 to the variance).
- **Negative a.** E(X) = 3 gives E(5 − 2X) = 5 − 2 × 3 = 5 − 6 = **−1**. Var(X) = 4 gives Var(5 − 3X) = (−3)² × 4 = 9 × 4 = **36** (not −12, and not 41).

### One-minute recap

- A random variable is a numerical description of the outcome of an experiment; chance decides its value.
- Discrete = countable values (count it); continuous = any value in an interval (measure it); for continuous X, P(X = c) = 0.
- Valid distribution: every 0 ≤ P(x) ≤ 1 and ΣP(x) = 1; use ΣP(x) = 1 to find a missing p or constant k.
- CDF: F(x) = P(X ≤ x); P(a < X ≤ b) = F(b) − F(a).
- E(X) = Σx P(x) = the population mean = long-run average; E(X²) = Σx² P(x).
- Var(X) = E(X²) − [E(X)]², never negative; σ = √Var(X).
- E(aX + b) = aE(X) + b; Var(aX + b) = a²Var(X); adding a constant leaves variance unchanged.
- Expected profit: losses are negative; choose the option with the highest expected profit.

### Theory practice

**Question:** A discrete random variable X has P(X = x) = k(x + 1) for x = 0, 1, 2, 3. Find k, E(X), Var(X), and Var(4X − 1).

*Solution:*

- ΣP(x) = k(1 + 2 + 3 + 4) = 10k = 1, so k = 0.1. The probabilities are 0.1, 0.2, 0.3, 0.4.
- E(X) = 0 × 0.1 + 1 × 0.2 + 2 × 0.3 + 3 × 0.4 = 0 + 0.2 + 0.6 + 1.2 = 2.0.
- E(X²) = 0 × 0.1 + 1 × 0.2 + 4 × 0.3 + 9 × 0.4 = 0 + 0.2 + 1.2 + 3.6 = 5.0.
- Var(X) = 5.0 − 2.0² = 5.0 − 4.0 = 1.0.
- Var(4X − 1) = 4² × 1.0 = 16 (the −1 has no effect). Also E(4X − 1) = 4 × 2 − 1 = 7.
