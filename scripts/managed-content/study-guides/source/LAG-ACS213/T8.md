## Topic 8: Sequences and Series

**What you must know:** sequence and series language (terms, nth term, recursion, factorial, sigma notation, partial sums); arithmetic progressions (nth term, sums, means) and their salary, seating, prize and instalment problems; geometric progressions (nth term, sums, sum to infinity, means) and their growth, depreciation, population and interest problems.

### Lesson 8.1: Sequences, series and notation

**Must know**

- **Sequence:** an ordered list of numbers formed by a definite rule, a\_1, a\_2, a\_3, ... Formally an **infinite sequence** is a function whose domain is the positive integers; its values are the **terms**. If the domain is only the first n positive integers, it is a **finite sequence**.
- **Series:** the **sum** of the terms of a sequence. 2, 5, 8, 11, ... is a sequence; 2 + 5 + 8 + 11 + ... is a series.
- **nth partial sum:** the sum of the first n terms, S\_n = a\_1 + a\_2 + ... + a\_n (a finite series). Adding all terms of an infinite sequence gives an **infinite series**.
- **nth term (general term):** a formula a\_n that gives any term from its position n.
- **Recursion formula:** gives each term from earlier ones, plus starting value(s). **Fibonacci sequence:** a\_0 = 1, a\_1 = 1, a\_k = a\_(k−2) + a\_(k−1) for k ≥ 2, giving 1, 1, 2, 3, 5, 8, ...
- **Factorial:** n! = 1 × 2 × 3 × ... × n, and **0! = 1** by definition. 1! = 1, 2! = 2, 3! = 6, 4! = 24, 5! = 120.
- **Sigma notation:** sum from i = 1 to n of a\_i = a\_1 + a\_2 + ... + a\_n; i is the index of summation, 1 the lower limit, n the upper limit. Number of terms = upper − lower + 1.
- **4 properties of sums** (c a constant):
  1. sum of c (n times) = cn
  2. sum of c·a\_i = c × (sum of a\_i)
  3. sum of (a\_i + b\_i) = sum of a\_i + sum of b\_i
  4. sum of (a\_i − b\_i) = sum of a\_i − sum of b\_i
- There is **no** product rule: sum of (a\_i·b\_i) is NOT (sum of a\_i)(sum of b\_i).

**Explain more**

- **Writing terms:** substitute n = 1, 2, 3, ... (or n = 0, 1, ... if told to begin at 0).
  - a\_n = 3n − 2: 1, 4, 7, 10.
  - a\_n = 3 + (−1)^n: n = 1 gives 3 − 1 = 2, n = 2 gives 3 + 1 = 4: so 2, 4, 2, 4. Odd n makes (−1)^n = −1.
  - a\_n = (−1)^n/(2n + 1): −1/3, 1/5, −1/7, 1/9, −1/11.
  - a\_n = 2^n/n! from n = 0: 1/1 = 1, 2/1 = 2, 4/2 = 2, 8/6 = 4/3, 16/24 = 2/3.
  - Recursion a\_1 = −4, a\_n = a\_(n−1) − 2: −4, −6, −8, −10.
- **Evaluating sums:** list the terms and add, or use AP/GP formulas (Lessons 8.2, 8.4).
  - sum i = 1 to 4 of (3i − 2) = 1 + 4 + 7 + 10 = 22.
  - sum i = 1 to 5 of (i² − 3) = −2 + 1 + 6 + 13 + 22 = 40.
  - sum k = 3 to 6 of (1 + k²) = 10 + 17 + 26 + 37 = 90.
  - sum k = 1 to 20 of (4k + 1): by properties, 4(1 + 2 + ... + 20) + 20 = 4(210) + 20 = 860.
  - sum n = 5 to 14 of (2n − 3): 10 terms, 7 + 9 + ... + 25 = (10/2)(7 + 25) = 160.
  - sum i = 0 to 8 of 1/i! = 1 + 1 + 0.5 + 0.166667 + ... = 2.71828 (5 d.p.), close to e.
- **Sigma from a list:** 3 + 7 + 11 + ... + 79 has a\_k = 4k − 1; 4k − 1 = 79 gives k = 20, so it is sum k = 1 to 20 of (4k − 1). Trap: the upper limit is the **number of terms** (20), not the last term (79).
- For sum i = 1 to ∞ of 3/10^i: third partial sum S\_3 = 0.3 + 0.03 + 0.003 = 0.333; the full sum is 1/3 (Lesson 8.4).

### Lesson 8.2: Arithmetic progressions (AP)

**Must know**

- **Arithmetic sequence (AP):** consecutive terms differ by a constant, the **common difference** d = a\_2 − a\_1 = a\_3 − a\_2 = ...
- **nth term:** a\_n = a + (n − 1)d (a = first term). Recursion: a\_(n+1) = a\_n + d.
- **Sum of first n terms:** S\_n = (n/2)[2a + (n − 1)d] = (n/2)(a + l), where l = last term.
- **Number of terms:** n = (l − a)/d + 1.
- **Arithmetic mean** of a and c: b = (a + c)/2. Three numbers a, b, c are in AP when **2b = a + c**.
- **Special sums:** 1 + 2 + ... + N = N(N + 1)/2; first n odd numbers = n²; first n even numbers = n(n + 1).

| Unknown | Formula to use |
|---|---|
| a term | a\_n = a + (n − 1)d |
| a and d from two terms | subtract the two term equations |
| n from last term | l = a + (n − 1)d |
| total, d known | S\_n = (n/2)[2a + (n − 1)d] |
| total, last term known | S\_n = (n/2)(a + l) |

**Explain more**

- **Terms:** a = 3, d = −1: a\_33 = 3 + 32(−1) = −29. a = 27, d = −5: a\_10 = 27 − 45 = −18. 7, 11, 15, ...: a\_20 = 7 + 19(4) = 83. 2, 9, ...: d = 7, a\_9 = 2 + 8(7) = 58.
- **nth-term formula:** a = 2, d = 3: a\_n = 2 + (n − 1)3 = **3n − 1**.
- **Two given terms:** a\_4 = 20 and a\_13 = 65. a + 3d = 20 and a + 12d = 65; subtract: 9d = 45, d = 5, a = 5, a\_11 = 5 + 50 = 55.
  - 3rd term 14, 10th term 49: 7d = 35, d = 5, a = 14 − 10 = 4.
  - 7th term 15, 9th term 27: 2d = 12, d = 6, a = 15 − 36 = −21; S\_50 = 25[2(−21) + 49(6)] = 25(252) = 6,300.
  - mth term n and nth term m: (m − n)d = n − m, so d = −1, a = m + n − 1, and the rth term = m + n − 1 − (r − 1) = **m + n − r**.
- **Number of terms:** 8, 13, ..., 208: n = (208 − 8)/5 + 1 = 41.
- **Sums:**
  - 17, 24, 31, ... 40 terms: S = 20[34 + 39(7)] = 20(307) = 6,140.
  - 7 + 10 + 13 + ... 40 terms: 20[14 + 117] = 2,620. 5 + 7.5 + 10 + ... 25 terms: 12.5[10 + 60] = 875.
  - 5, 16, 27, ... 150 terms: 75[10 + 149(11)] = 75(1,649) = 123,675.
  - 62 + 60 + ... + 40: d = −2, n = (40 − 62)/(−2) + 1 = 12, S = 6(62 + 40) = 612.
  - 12 + 17 + ... + 112: n = 21, S = (21/2)(124) = 1,302.
  - 1 + 3 + ... + 19 (10 odd numbers) = 10² = 100. First 25 even numbers = 25 × 26 = 650. 1 to 100 = 100 × 101/2 = 5,050; 1 to N = N(N + 1)/2.
- **Multiples:** multiples of 5 from 1 to 1,000: 5, 10, ..., 1,000, n = 200, S = 100(1,005) = 100,500. Numbers 1 to 200 **excluding** multiples of 5: 20,100 − (5 + ... + 200) = 20,100 − 20(205) = 20,100 − 4,100 = 16,000.
- **Find n from sum and ends:** a = −4, l = 146, S = 7,171: 7,171 = (n/2)(142), n = 101; then 146 = −4 + 100d, d = 1.5. Likewise a = 2, l = 32, S = 119: 119 = 17n, n = 7; 32 = 2 + 6d, d = 5; series 2 + 7 + 12 + 17 + ...
- **Equal sums:** 13 + 16.5 + 20 + ... and 3 + 7 + 11 + ... have equal S\_n: (n/2)[26 + 3.5(n − 1)] = (n/2)[6 + 4(n − 1)], so 22.5 + 3.5n = 2 + 4n, 0.5n = 20.5, n = 41.
- **Means:** three arithmetic means between 6 and 30 make 5 terms: 30 = 6 + 4d, d = 6: means 12, 18, 24. If 2k + 1, 5k − 2, 6k + 3 are in AP: 2(5k − 2) = (2k + 1) + (6k + 3), 10k − 4 = 8k + 4, k = 4.
- **Recognising an AP:** 2.5, 3, 3.5, ... (d = 0.5), 20, 17, 14, ... (d = −3), −7, −3, 1, ... (d = 4) are APs; 3, 6, 12, 24 is not (it doubles).

### Lesson 8.3: AP applications in business

**Must know**

- A quantity that changes by a **fixed naira amount (or fixed number)** each period is an AP: salary with a fixed raise, rows gaining a fixed number of seats, prizes falling by a fixed amount, instalments rising by a fixed amount, straight-line depreciation.
- **The value in year n** uses a\_n = a + (n − 1)d. **The total over n years** uses S\_n.
- If the unknown is n and it appears inside S\_n, you get a **quadratic**: keep the positive whole-number root.

**Explain more**

- **Salary:** start ₦32,500, raise ₦1,500. 6th year: 32,500 + 5(1,500) = ₦40,000. Total over 6 years: (6/2)(32,500 + 40,000) = ₦217,500.
  - Lagos bank trainee, ₦1,800,000 plus ₦150,000 a year: 8th year = 1,800,000 + 7(150,000) = ₦2,850,000.
  - ₦960,000 plus ₦60,000, total over 10 years: 5[1,920,000 + 9(60,000)] = 5(2,460,000) = ₦12,300,000.
  - When is ₦600,000 plus ₦40,000 exactly ₦1,000,000? 600,000 + (n − 1)40,000 = 1,000,000, n − 1 = 10, **11th year**.
  - Total ₦3,500,000 over 5 years from ₦600,000: 3,500,000 = 2.5(1,200,000 + 4d), 1,400,000 = 1,200,000 + 4d, d = ₦50,000.
- **Trap:** the raise is multiplied by **n − 1**, not n. For ₦50,000 plus ₦5,000 over 6 years, S = 3[100,000 + 5(5,000)] = ₦375,000, not 3[100,000 + 6(5,000)] = ₦390,000.
- **Seating:** 30 rows, 20 seats then +4: S = 15[40 + 29(4)] = 15(156) = 2,340. Ikeja hall, 25 rows, 18 then +3: 12.5[36 + 72] = 1,350.
  - 800 seats, first row 20, +4 per row: 800 = (n/2)[40 + 4(n − 1)] = 2n² + 18n, so n² + 9n − 400 = 0, n = [−9 + √(81 + 1,600)]/2 = (−9 + 41)/2 = **16 rows**.
- **Prizes (d negative):** 8 prizes from ₦200 falling ₦25: 4[400 + 7(−25)] = 4(225) = ₦900. 16 golfers from ₦1,000 falling ₦50: 8[2,000 − 750] = ₦10,000. Top 10 teams from ₦500,000 falling ₦40,000: 5[1,000,000 − 360,000] = ₦3,200,000.
  - ₦2,100,000 shared by 6 agents, each ₦50,000 less: 2,100,000 = 3[2a − 250,000], 2a = 950,000, first prize a = ₦475,000.
- **Profit and sales:** profit ₦8,000 rising ₦1,500 for 5 more years (6 years in all): 3[16,000 + 7,500] = ₦70,500. Ogun State poultry farm, ₦450,000 rising ₦75,000 for 7 years (8 years in all): 4[900,000 + 525,000] = ₦5,700,000. Sales ₦10,000 rising ₦7,500 for 9 years (10 years in all): 5[20,000 + 67,500] = ₦437,500. Trap: "increase for 9 years" means 10 terms.
- **Instalments:** debt ₦6,682, first ₦1, each ₦5 more: 6,682 = (n/2)[2 + 5(n − 1)], so 13,364 = 5n² − 3n, 5n² − 3n − 13,364 = 0, n = [3 + √(9 + 267,280)]/10 = (3 + 517)/10 = **52** instalments.
  - Interest-free loan ₦14,500 in 10 instalments, first ₦1,000: 14,500 = 5(2,000 + 9d), d = 100, last = 1,000 + 9(100) = ₦1,900.
  - Savings ₦16,500 in 10 years, ₦100 more each year: 16,500 = 5(2a + 900), 2a = 2,400, first year a = ₦1,200.
- **Production:** 500 TV sets in year 1, 4,500 in 5 years: 4,500 = 2.5(1,000 + 4d), d = 200 units; 9th year = 500 + 8(200) = 2,100.
- **Shares:** price ₦100 rising ₦10 a year; x shares worth ₦5,700 in the 10th year. 10th-year price = 100 + 9(10) = ₦190, so x = 5,700/190 = 30 shares. First-year cost = 30 × 100 = ₦3,000; 5th-year worth = 30 × 140 = ₦4,200.
- **AP or GP?** Machine P losing ₦150,000 a year is an **arithmetic** sequence; machine Q losing 12% a year is **geometric**.

### Lesson 8.4: Geometric progressions (GP)

**Must know**

- **Geometric sequence (GP):** each term is a constant multiple of the one before; **common ratio** r = a\_2/a\_1 = a\_3/a\_2 = ... (r ≠ 0).
- **nth term:** a\_n = a·r^(n−1). Recursion: a\_(n+1) = a\_n·r.
- **Sum of first n terms:** S\_n = a(r^n − 1)/(r − 1), convenient when r > 1; S\_n = a(1 − r^n)/(1 − r), convenient when r < 1. With last term l: S\_n = (lr − a)/(r − 1).
- **Sum to infinity:** S∞ = a/(1 − r), **only when |r| < 1** (−1 < r < 1). When |r| ≥ 1 the series has no finite sum.
- **Geometric mean** of a and c: b = √(ac). Non-zero a, b, c are in GP when **b² = ac**.
- **Arithmetic versus geometric series:** in an arithmetic series consecutive terms differ by a constant amount (d); in a geometric series each term is a constant multiple of the one before (r).

**Explain more**

- **Terms:** a = 3, r = 2: 3, 6, 12, 24, 48. a = 2, r = −3: a\_4 = 2(−3)³ = −54. 5, 15, 45, ...: a\_12 = 5(3^11) = 885,735. 128, 64, 32, ...: a\_7 = 128(1/2)^6 = 2. a = 20, r = 1.05: a\_15 = 20(1.05)^14 = 39.60 (2 d.p.). 1, 3, 9, ...: a\_10 = 3^9 = 19,683.
- **Recognising a GP:** 4, 10, 25, 62.5 has r = 2.5. 1, 4, 9, 16 (squares) and 2, 3, 5, 8 (Fibonacci-type) are neither AP nor GP.
- **Two given terms:** divide them. 2nd term 12, 5th term 324: ar⁴/ar = 27, r³ = 27, r = 3, a = 12/3 = 4. 4th term 125, 10th term 125/64: r^6 = 1/64, r = 1/2 (positive terms), a\_14 = a\_10·r⁴ = (125/64)(1/16) = **125/1024**.
- **Means:** GM of 4 and 81 = √324 = 18. Two geometric means between 3 and 192: 192 = 3r³, r³ = 64, r = 4: means 12 and 48.
- **Sums:**
  - 7, 14, 28, ... 11 terms: 7(2^11 − 1)/1 = 7(2,047) = 14,329.
  - −5, −15, −45, ... 6 terms: −5(3^6 − 1)/2 = −5(364) = −1,820.
  - 4 + 12 + 36 + ... 6 terms: 4(728)/2 = 1,456. 1 + 3 + 9 + ... 10 terms: (3^10 − 1)/2 = 29,524.
  - 48 + 24 + 12 + ... 5 terms: 48(1 − 1/32)/(1/2) = 96(31/32) = 93.
  - 2 − 6 + 18 − ... 6 terms (r = −3): 2(1 − 729)/(1 + 3) = 2(−728)/4 = −364.
  - sum i = 1 to 12 of 4(0.3)^i: first term 4(0.3) = 1.2, so 1.2(1 − 0.3^12)/0.7 = 1.714. With exponent (i − 1) the first term is 4: 4(1 − 0.3^12)/0.7 = 5.714 (3 d.p.). Trap: check the first term before using the formula.
  - S\_n = 255, r = 2, last term 128: 255 = (2 × 128 − a)/1, a = 1; 128 = 2^(n−1), n = 8.
- **Sum to infinity:** 4(0.6)^n from n = 0: 4/0.4 = 10. 3 + 0.3 + 0.03 + ...: 3/0.9 = 10/3. 0.3 + 0.03 + ...: 0.3/0.9 = 1/3. 1 + 1/2 + 1/4 + ...: 1/(1/2) = 2. 81 + 27 + 9 + ...: 81/(2/3) = 121.5. 1/5 − 2/25 + 4/125 − ...: r = −2/5, S = (1/5)/(7/5) = 1/7.
  - First term 15, S∞ = 60: 60 = 15/(1 − r), 1 − r = 0.25, r = 0.75.
  - **Trap:** 3 + 6 + 12 + ... has r = 2, so |r| > 1 and there is **no** sum to infinity; 3/(1 − 2) = −3 is wrong.
  - **Alternating pairs:** 4/7 − 5/7² + 4/7³ − 5/7⁴ + ... splits into two GPs with r = 1/49: (4/7)/(48/49) − (5/49)/(48/49) = 28/48 − 5/48 = **23/48**.
- **5 + 55 + 555 + ... to n terms:** = (5/9)(9 + 99 + 999 + ...) = (5/9)[(10 + 10² + ... + 10^n) − n] = (5/9)[10(10^n − 1)/9 − n] = **(5/81)(10^(n+1) − 10 − 9n)**. Replace 5 by 4 or 7 for 4 + 44 + ... and 7 + 77 + ...: (4/81)(10^(n+1) − 10 − 9n), (7/81)(10^(n+1) − 10 − 9n).

### Lesson 8.5: GP applications: growth, depreciation and interest

**Must know**

- Growth by a fixed **percentage** is a GP with r = 1 + rate; decline (depreciation) by a fixed percentage is a GP with r = 1 − rate.
- If a is the **first year's** value, the **nth year's** value = a·r^(n−1). If a is the value **now**, the value **after n years** (end of year n) = a·r^n; **one year ago** = a/r.
- **Compound interest balance sequence:** A\_n = P(1 + i/m)^n after n periods (m periods a year), so after t years A = P(1 + i/m)^(mt).
- **Total over n years** (sales, consumption): S\_n = a(r^n − 1)/(r − 1).
- To find n in r^n = k, take logs: **n = log k / log r**.

**Explain more**

- **Population:** 2,624,000 growing 2.5% a year. In 3 years: 2,624,000 × 1.025³ = 2,624,000 × 1.076890625 = **2,825,761**. One year ago: 2,624,000 ÷ 1.025 = **2,560,000**.
- **Sales growth:** Abuja supermarket, ₦40,000,000 in year 1, +10%: year 5 = 40,000,000(1.1)⁴ = ₦58,564,000 (power 4, not 5). ₦12,000,000 rising 5%, total over 6 years: 12,000,000(1.05^6 − 1)/0.05 = ₦81,622,954 (nearest naira).
- **Depreciation:** generator ₦2,500,000 losing 20% a year: end of 4 years = 2,500,000(0.8)⁴ = ₦1,024,000. Car ₦8,000,000 worth ₦5,120,000 after 2 years: r² = 0.64, r = 0.8, rate = 1 − 0.8 = **20%**.
  - V = 4,000,000(0.85)^n: 0.85 = 1 − 0.15, so the van **loses 15%** of its value each year (not 85%, not a fixed ₦600,000).
- **First year above a target:** 2,000 units growing 50%: 2,000(1.5)^(n−1) > 20,000, 1.5^(n−1) > 10, n − 1 > log 10/log 1.5 = 5.68, so n − 1 = 6, **7th year** (22,781.25 units; the 6th year gives only 15,187.5).
- **Salary offers:** Offer 1: ₦2,000,000 plus ₦200,000 (AP); 5th year = 2,000,000 + 4(200,000) = ₦2,800,000. Offer 2: ₦2,000,000 rising 8% (GP); 5th year = 2,000,000(1.08)⁴ = ₦2,720,977.92. Offer 1 is higher by ₦79,022 (nearest naira).
- **Resource exhaustion:** reserves 250 million tonnes, use 20 million tonnes rising 2% a year. Exhausted when 20(1.02^n − 1)/0.02 = 250: 1,000(1.02^n − 1) = 250, 1.02^n = 1.25, n = log 1.25/log 1.02 = 0.09691/0.00860 = **11.27 years** (2 d.p.).
- **Compound interest:** ₦25 at 7% compounded monthly, A\_n = 25(1 + 0.07/12)^n: A\_1 = 25.15, A\_2 = 25.29, A\_3 = 25.44 (2 d.p.).
  - ₦5,000 at 3% compounded quarterly, A\_n = 5,000(1.0075)^n: A\_0 = ₦5,000.00, A\_1 = ₦5,037.50, A\_2 = ₦5,075.28. After 10 years n = 40: 5,000(1.0075)^40 = **₦6,741.74**.
- **Annuities** are GP sums too: equal payments R each period at rate i give R + R(1 + i) + ... + R(1 + i)^(n−1) = R[(1 + i)^n − 1]/i.

### One-minute recap

- Sequence = ordered list; series = sum of its terms; S\_n = nth partial sum.
- 0! = 1; sigma upper limit counts terms; no product rule for sums.
- AP: a\_n = a + (n − 1)d; S\_n = (n/2)[2a + (n − 1)d] = (n/2)(a + l); 2b = a + c.
- Fixed naira change = AP; multiply the raise by n − 1.
- GP: a\_n = ar^(n−1); S\_n = a(r^n − 1)/(r − 1); b² = ac.
- S∞ = a/(1 − r) only if |r| < 1; otherwise no finite sum.
- Fixed percentage change = GP with r = 1 ± rate; "after n years" = ar^n, "nth year" = ar^(n−1).
- Solve r^n = k with n = log k/log r; quadratic in n: keep the positive whole root.

### Theory practice

**Question:** The 3rd term of a geometric progression is 18 and the 6th term is 486. Find the first term, the common ratio and the sum of the first 5 terms.

*Solution:* ar² = 18 and ar⁵ = 486. Divide: r³ = 486/18 = 27, so r = 3. Then a = 18/9 = 2. S\_5 = a(r^5 − 1)/(r − 1) = 2(243 − 1)/2 = **242**. Check: 2 + 6 + 18 + 54 + 162 = 242.
