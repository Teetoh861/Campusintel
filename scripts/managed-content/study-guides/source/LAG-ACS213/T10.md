## Topic 10: Consumption and Market Penetration

**What you must know:** consumption and saving functions with MPC, MPS, APC and APS; recovering consumption or saving from a marginal propensity by integration; minimum saving, equilibrium income and the multiplier; market penetration, logistic and learning-curve models.

### Lesson 10.1: Consumption, saving and the propensities

**Must know**

- **Income identity:** income is either consumed or saved, so Y = C + S, and S = Y − C.
- **Consumption function:** C = f(Y), where C is consumption and Y is (disposable) income.
- **Marginal propensity to consume (MPC):** MPC = dC/dY = f'(Y), the extra consumption from one extra naira of income.
- **Marginal propensity to save (MPS):** MPS = dS/dY.
- Differentiating Y = C + S with respect to Y gives 1 = dC/dY + dS/dY, so **MPC + MPS = 1**. Hence MPS = 1 − MPC and MPC = 1 − MPS.
- **Average propensities:** APC = C/Y and APS = S/Y, with APC + APS = 1.
- **Linear consumption function:** C = a + bY, with a > 0 and 0 < b < 1.
    1. **a = autonomous consumption**, consumption when Y = 0.
    2. **b = MPC**, the same at every income level; MPS = 1 − b.
    3. **Saving function:** S = Y − (a + bY) = (1 − b)Y − a.
    4. **APC = a/Y + b:** it is not constant; it falls towards b as Y rises.
- **Break-even income:** where C = Y (saving is zero): Y = a/(1 − b). Below it, S < 0 (**dissaving**).

| Measure | Formula | For C = a + bY |
|---|---|---|
| MPC | dC/dY | b (constant) |
| MPS | dS/dY = 1 − MPC | 1 − b (constant) |
| APC | C/Y | a/Y + b (falls as Y rises) |
| APS | S/Y = 1 − APC | (1 − b) − a/Y |

**Explain more**

Worked example: C = 50 + 0.75Y (₦ billion). Find everything at Y = 400.
- MPC = 0.75; MPS = 1 − 0.75 = 0.25.
- C = 50 + 0.75(400) = 50 + 300 = 350. S = 400 − 350 = 50.
- APC = 350/400 = 0.875. APS = 50/400 = 0.125 (check: 0.875 + 0.125 = 1).
- Saving function: S = Y − 50 − 0.75Y = 0.25Y − 50.
- Break-even income: Y = 50/(1 − 0.75) = 50/0.25 = ₦200 billion. At Y = 100, S = 25 − 50 = −25, dissaving of ₦25 billion.

Trap: in C = a + bY the MPC is b at every income, but the APC is not: APC = 50/Y + 0.75 stays above 0.75 and sinks towards it. The saving function has −a (not +a, and not bY − a).

Finding income from the APC: for C = 40 + 0.8Y, at what income is APC = 0.9? Set 40/Y + 0.8 = 0.9, so 40/Y = 0.1 and Y = ₦400 billion.

Finding the function from two points: C = 120 when Y = 100, and C = 280 when Y = 300.
- b = change in C / change in Y = (280 − 120)/(300 − 100) = 160/200 = 0.8.
- a = 120 − 0.8(100) = 120 − 80 = 40. So C = 40 + 0.8Y.

Finding autonomous consumption from MPS and one saving figure: a household in Kaduna has MPS = 0.25 and saves ₦20,000 when income is ₦200,000. Saving is S = (1 − b)Y − a = 0.25Y − a, so 20,000 = 0.25(200,000) − a = 50,000 − a, and a = ₦30,000.

Units: if C and Y are "in thousands of naira", a break-even answer of Y = 450 means ₦450,000.

### Lesson 10.2: From marginal propensity to total function (integration)

**Must know**

- Consumption is the integral of MPC; saving is the integral of MPS:
    1. C = ∫ MPC dY = ∫ f'(Y) dY + k
    2. S = ∫ MPS dY + k
- **Power rule for integration:** ∫ Y^n dY = Y^(n+1)/(n + 1) + k, for n ≠ −1. Add 1 to the power, then divide by the new power.
- ∫ b dY = bY (a constant integrates to constant × Y).
- **Shifted form:** ∫ (Y + c)^n dY = (Y + c)^(n+1)/(n + 1) + k.
- Rewrite roots first: 1/sqrt(Y) = Y^(−1/2); 1/Y^(1/3) = Y^(−1/3).
- **Find k** from the given condition (for example C = 6 when Y = 0). Usually k = autonomous consumption, but not when a term such as sqrt(Y + 9) is non-zero at Y = 0.
- **Change in consumption** when income moves from Y1 to Y2: ∫ from Y1 to Y2 of MPC dY = C(Y2) − C(Y1). No k is needed.

**Explain more**

Key results of the power rule (memorise them):
- ∫ 0.4Y^(−1/2) dY = 0.4 × Y^(1/2)/(1/2) = 0.8Y^(1/2). Rule: c/sqrt(Y) integrates to 2c·sqrt(Y).
- ∫ 0.1Y^(−1/3) dY = 0.1 × Y^(2/3)/(2/3) = 0.15Y^(2/3).

Worked example 1 (consumption from MPC): MPC = 0.6 + 0.3/sqrt(Y), and C = 20 when Y = 0 (₦ billion).
- Step 1: C = ∫ (0.6 + 0.3Y^(−1/2)) dY.
- Step 2: C = 0.6Y + 0.3 × Y^(1/2)/(1/2) + k = 0.6Y + 0.6Y^(1/2) + k.
- Step 3: at Y = 0, C = 20, so 0 + 0 + k = 20 and k = 20.
- Step 4: C = 0.6Y + 0.6sqrt(Y) + 20.

Trap: a common wrong Step 2 halves the coefficient (writing 0.06Y^(1/2) for ∫ 0.12Y^(−1/2) dY). Dividing by 1/2 doubles it: the right term is 0.24Y^(1/2). Another wrong option leaves "+ K" or "+ C" unsolved, or writes 0.3 instead of 0.3Y (forgetting to integrate the constant).

Worked example 2 (saving from MPS, condition not at zero): MPS = 0.3 − 0.1Y^(−1/2), and S = 0 when Y = 81.
- S = 0.3Y − 0.1 × Y^(1/2)/(1/2) + k = 0.3Y − 0.2Y^(1/2) + k.
- At Y = 81: 0.3(81) − 0.2(9) + k = 0, so 24.3 − 1.8 + k = 0 and k = −22.5.
- S = 0.3Y − 0.2sqrt(Y) − 22.5. A negative k means dissaving at very low income.

Worked example 3 (shifted root): MPC = 0.5 + 1/sqrt(Y + 4), with C = 12 when Y = 0.
- ∫ (Y + 4)^(−1/2) dY = (Y + 4)^(1/2)/(1/2) = 2sqrt(Y + 4).
- C = 0.5Y + 2sqrt(Y + 4) + k. At Y = 0: 0 + 2sqrt(4) + k = 12, so 4 + k = 12 and k = 8.
- C = 0.5Y + 2sqrt(Y + 4) + 8. Here k is not 12, because the root term is 4 at Y = 0.

Worked example 4 (change in consumption): MPC = 0.7 + 0.4/sqrt(Y); income rises from 25 to 100.
- C(Y) without k = 0.7Y + 0.8sqrt(Y).
- Change = [0.7(100) + 0.8(10)] − [0.7(25) + 0.8(5)] = 0.7(75) + 0.8(5) = 52.5 + 4 = ₦56.5 billion.

Converting between propensities: if MPS = 0.7 − 0.4/sqrt(Y), then MPC = 1 − MPS = 0.3 + 0.4/sqrt(Y) (subtract every term; the sign of the root term flips). If MPS is a constant 0.25, MPC = 0.75, so with C = 9 at Y = 0, C = 0.75Y + 9.

### Lesson 10.3: MPC at a point, minimum saving, equilibrium and the multiplier

**Must know**

- **Power rule for differentiation:** d/dY (Y^n) = n·Y^(n−1); d/dY (constant) = 0. So d/dY (sqrt(Y)) = 1/(2sqrt(Y)).
- **MPC at a given income:** differentiate C, then substitute Y.
- **Smallest (or largest) saving:** S = Y − C; set dS/dY = 0 and solve; d²S/dY² > 0 confirms a minimum.
- **Simple national-income model:** Y = C + I, with C = a + bY and investment I fixed.
    1. **Equilibrium income:** Y = (a + I)/(1 − b).
    2. **Equilibrium consumption:** C = a + bY (or C = Y − I).
    3. **Investment multiplier:** k = 1/(1 − MPC) = 1/MPS.
    4. **Change in income:** change in Y = k × change in I.

**Explain more**

MPC at a point: C = 20 + 0.6Y + 0.8sqrt(Y). Then MPC = 0.6 + 0.8 × 1/(2sqrt(Y)) = 0.6 + 0.4/sqrt(Y). At Y = 16: MPC = 0.6 + 0.4/4 = 0.7, so MPS = 0.3.

Minimum saving: C(x) = 8 + 0.8x + 0.8sqrt(x), where x is national income. Find the MPC and the income giving the smallest total saving.
- MPC = C'(x) = 0.8 + 0.4/sqrt(x).
- S = x − C = x − 8 − 0.8x − 0.8sqrt(x) = 0.2x − 0.8sqrt(x) − 8.
- dS/dx = 0.2 − 0.4/sqrt(x) = 0, so sqrt(x) = 0.4/0.2 = 2 and x = 4.
- d²S/dx² = 0.2x^(−3/2) > 0, so this is a minimum. S(4) = 0.8 − 1.6 − 8 = −8.8.
- The answer is x = 4, not sqrt(x) = 2. Saving is smallest where MPS = 0 (MPC = 1).

Equilibrium: C = 100 + 0.8Y and I = 60 (₦ billion).
- Y = C + I = 100 + 0.8Y + 60, so 0.2Y = 160 and Y = ₦800 billion.
- C = 100 + 0.8(800) = ₦740 billion (check: 740 + 60 = 800).
- Multiplier k = 1/(1 − 0.8) = 1/0.2 = 5. If I rises by ₦10 billion, Y rises by 5 × 10 = ₦50 billion.

Traps: the multiplier is 1/MPS, not MPS (0.2) and not 1/MPC (1.25). With MPS = 0.25, k = 4, and a ₦15 billion rise in I raises Y by ₦60 billion. Asked for equilibrium consumption, do not stop at Y.

### Lesson 10.4: Market penetration (limited growth)

**Must know**

- **Market penetration model:** P(t) = M(1 − e^(−kt)), with M > 0 and k > 0, where P(t) is the share (or number) of the target market that has adopted the product t periods after launch.
    1. **M = saturation level**, the share approached in the long run (as t grows, e^(−kt) → 0, so P → M).
    2. **k = penetration rate constant**; larger k means faster adoption.
    3. P(0) = M(1 − 1) = 0.
- **Graph:** starts at 0 and rises at a decreasing rate towards M (concave, levels off; never passes M).
- The same shape: advertising response R = 1 − e^(−0.05t) (M = 1, t = number of times the advert runs). N(t) = A − Ae^(−kt) is the same model with M = A.
- **Natural log facts:** ln(e^x) = x; e^(−x) = 1/e^x; ln(1/a) = −ln a.
- **Time to reach a share P:** e^(−kt) = 1 − P/M, so t = −ln(1 − P/M)/k.
- **Time to reach half of M:** t = ln 2/k.
- **Finding k** from one observed share P at time t: k = −ln(1 − P/M)/t.
- **Rate of penetration:** d/dt (e^(−kt)) = −k·e^(−kt), so dP/dt = Mk·e^(−kt).
- **New adopters between t1 and t2:** P(t2) − P(t1) = M(e^(−k·t1) − e^(−k·t2)).

**Explain more**

Worked example: the share of Lagos pharmacies stocking a new Nigerian-made malaria test kit t months after launch is P(t) = 0.7(1 − e^(−0.25t)).
- After 4 months: P(4) = 0.7(1 − e^(−1)) = 0.7(1 − 0.367879) = 0.7(0.632121) = 0.44248, about 44.25%.
- Long run: 70% (M = 0.7).
- Time to 50%: 0.5 = 0.7(1 − e^(−0.25t)), so e^(−0.25t) = 1 − 0.5/0.7 = 0.285714. Take ln: −0.25t = ln 0.285714 = −1.25276, so t = 5.01 months.
- Half of saturation (35%): t = ln 2/0.25 = 0.693147/0.25 = 2.77 months.
- Rate at t = 2: dP/dt = 0.7 × 0.25 × e^(−0.5) = 0.175 × 0.606531 = 0.10614, about 10.61 percentage points per month.

Finding k: P(t) = 0.9(1 − e^(−4k)) and the share after 4 years is 60%. Then 0.6/0.9 = 1 − e^(−4k), so e^(−4k) = 1/3, −4k = ln(1/3) = −1.098612, and k = 0.275 (to 3 decimal places).

Adopters in one period: N(t) = 20,000(1 − e^(−0.5t)) households. New subscribers in the second year (t = 1 to t = 2) = 20,000(e^(−0.5) − e^(−1)) = 20,000(0.606531 − 0.367879) = 20,000(0.238652) = 4,773 (nearest whole number). Trap: N(2) alone (12,642) is the total after 2 years, not the second year's intake.

Advertising response: R = 1 − e^(−0.05t) gives 4.88% after 1 showing, 22.12% after 5 and 63.21% after 20: each extra showing adds less.

### Lesson 10.5: Logistic growth and learning curves

**Must know**

- **Logistic model:** N(t) = M/(1 + A·e^(−kt)), with A, k > 0. M is the saturation level (carrying capacity); S-shaped: slow start, rapid middle growth, then levelling off at M.
- **Learning curve:** Q(t) = A − B·e^(−kt), with A, B, k > 0: output per period after t periods of training. A is the maximum output.
- Long run for both: e^(−kt) → 0. Time to reach output Q on a learning curve: e^(−kt) = (A − Q)/B, so t = −ln((A − Q)/B)/k.

| Model | Formula | Value at t = 0 | Long-run value | Shape |
|---|---|---|---|---|
| Market penetration | M(1 − e^(−kt)) | 0 | M | rises at a decreasing rate |
| Logistic | M/(1 + Ae^(−kt)) | M/(1 + A) | M | S-shaped |
| Learning curve | A − Be^(−kt) | A − B | A | rises at a decreasing rate |

**Explain more**

Logistic worked example: users of a new Abuja delivery app, N(t) = 20,000/(1 + 19e^(−0.5t)), t in months.
- At launch: N(0) = 20,000/(1 + 19) = 20,000/20 = 1,000 users.
- After 4 months: 19e^(−2) = 19 × 0.135335 = 2.571370, so N(4) = 20,000/3.571370 = 5,600 users (nearest whole number).
- Long run: 20,000 users. If N is in thousands (for example 360/(1 + 9e^(−0.5t)) thousand cartons), the limit is 360,000, not 360 or 36,000.

Learning-curve worked example: a trainee welder at a fabrication yard in Onne produces Q(t) = 50 − 30e^(−0.25t) joints per day after t days.
- Day 0: Q(0) = 50 − 30 = 20 joints.
- After 4 days: Q(4) = 50 − 30e^(−1) = 50 − 30(0.367879) = 50 − 11.036 = 38.96 joints per day.
- First reaching 45 joints: 45 = 50 − 30e^(−0.25t), so e^(−0.25t) = 5/30 = 1/6, −0.25t = ln(1/6) = −1.791759, and t = 7.17 days.
- Ceiling: 50 joints per day, never exceeded.

Trap: for a learning curve, Q(0) is A − B, not A; and do not confuse "after t days" (substitute t) with "after how many days" (solve with ln).

### One-minute recap

- Y = C + S, so MPC + MPS = 1 and APC + APS = 1.
- MPC = dC/dY, MPS = dS/dY, APC = C/Y, APS = S/Y.
- C = a + bY: a is autonomous consumption, b = MPC; S = (1 − b)Y − a; APC = a/Y + b falls towards b; break-even Y = a/(1 − b).
- C = ∫ MPC dY + k; c/sqrt(Y) integrates to 2c·sqrt(Y); find k from the given point.
- Minimum saving: set dS/dY = 0 (MPC = 1).
- Equilibrium Y = (a + I)/(1 − b); multiplier = 1/MPS.
- Penetration P = M(1 − e^(−kt)): starts at 0, rises at a decreasing rate to M; half of M at t = ln 2/k; dP/dt = Mke^(−kt).
- Logistic M/(1 + Ae^(−kt)): starts at M/(1 + A), S-shaped, tends to M. Learning curve A − Be^(−kt): starts at A − B, tends to A.

### Theory practice

**Question:** The marginal propensity to save is MPS = 0.2 − 0.1Y^(−1/2), and saving is zero when income is ₦25 billion. Find the saving function and the consumption function.

*Solution:*
- S = ∫ (0.2 − 0.1Y^(−1/2)) dY = 0.2Y − 0.1 × Y^(1/2)/(1/2) + k = 0.2Y − 0.2Y^(1/2) + k.
- At Y = 25: 0.2(25) − 0.2(5) + k = 0, so 5 − 1 + k = 0 and k = −4. Hence S = 0.2Y − 0.2sqrt(Y) − 4.
- C = Y − S = Y − 0.2Y + 0.2sqrt(Y) + 4 = 0.8Y + 0.2sqrt(Y) + 4.
- Check: MPC = 0.8 + 0.1Y^(−1/2), and MPC + MPS = 1.
