## Topic 4: Optimisation and Growth Models

**What you must know:** stationary points, the first- and second-derivative tests, concavity and inflection; minimising cost and maximising revenue and profit; monopoly, price discrimination and Cournot duopoly; partial derivatives and marginal analysis with two variables; unconstrained and Lagrange (constrained) optimisation; exponential growth and decay models.

### Lesson 4.1: Stationary points, maxima, minima and inflection

**Must know**

- **Rules you need:** d/dx (k) = 0; d/dx (x^n) = n·x^(n−1); d/dx (k·f) = k·f′; sum rule (differentiate term by term); product (uv)′ = u′v + uv′; quotient (u/v)′ = (v·u′ − u·v′)/v^2; chain d/dx f(g(x)) = f′(g(x))·g′(x); d/dx e^(kx) = k·e^(kx); d/dx ln x = 1/x; d/dx sqrt(u) = u′/(2 sqrt(u)).
- **Stationary (critical) point:** where f′(x) = 0. Maxima and minima are called turning points.
- **Second-derivative test** at f′(a) = 0:

| f″(a) | Conclusion |
|---|---|
| f″(a) < 0 | relative (local) maximum |
| f″(a) > 0 | relative (local) minimum |
| f″(a) = 0 | inconclusive: use the first-derivative test |

- **First-derivative test:** f′ changes + to − = maximum; − to + = minimum; no sign change = neither (a stationary point of inflection).
- **Concavity:** f″ > 0 concave upward; f″ < 0 concave downward. **Point of inflection:** where concavity changes (f″ = 0 or undefined and changes sign).
- **Point of diminishing returns:** the inflection point of a sales or output function; after it, each extra naira adds less.
- **Maximum/minimum value** = f(a), found by putting a back into the original f.

**Explain more**

- **Example (f(x) = x^3 − 9x^2 + 24x − 12):** f′(x) = 3x^2 − 18x + 24 = 3(x − 2)(x − 4) = 0, so x = 2 or 4. f″(x) = 6x − 18. f″(2) = −6 < 0: maximum, f(2) = 8 − 36 + 48 − 12 = 8. f″(4) = 6 > 0: minimum, f(4) = 64 − 144 + 96 − 12 = 4.
- **Constants:** for 15x^4 + 8x^3 − 18x^2 (maximum value 0 at x = 0; minima −11 at x = −1 and −2.808 at x = 3/5), adding +1 shifts every value up by 1 (1, −10, −1.808) but not the x-values.
- **When f″ = 0 (f(x) = (8/3)x^3 − x^4):** f′ = 8x^2 − 4x^3 = 4x^2(2 − x) = 0 at x = 0, 2. f″ = 16x − 12x^2; f″(2) = −16: maximum at (2, 64/3 − 16) = (2, 16/3). f″(0) = 0, and f′ is positive on both sides of 0, so x = 0 is neither a maximum nor a minimum.
- **Inflection (f(x) = x^3 − (3/2)x^2 + 5):** f″ = 6x − 3 = 0 at x = 1/2. f″ < 0 for x < 1/2 (concave downward), > 0 for x > 1/2 (concave upward). f(1/2) = 1/8 − 3/8 + 5 = 19/4. Point of inflection (1/2, 19/4).
- **Diminishing returns:** a tyre dealer's sales S(x) = −0.02x^3 + 3x^2 + 100 (both in ₦ thousands). S″ = −0.12x + 6 = 0 gives x = 50. S(50) = −2,500 + 7,500 + 100 = 5,100. So ₦50,000 on advertising, sales ₦5,100,000.

### Lesson 4.2: Optimising cost, revenue and profit

**Must know**

- **Definitions:** TR = R = p·x (write p from the demand equation first); MR = dR/dx; MC = dC/dx; AC = C/x; profit P = R − C.
- **Conditions:**

| Goal | First-order condition | Second-order condition |
|---|---|---|
| Minimum MC | d(MC)/dx = 0 | d^2(MC)/dx^2 > 0 |
| Minimum AC | d(AC)/dx = 0 | d^2(AC)/dx^2 > 0 |
| Maximum revenue | MR = 0 | R″ < 0 |
| Maximum profit | P′ = 0, i.e. **MR = MC** | P″ < 0 |
| Minimum total cost | C′ = 0 | C″ > 0 |

- **MC = AC at minimum AC:** AC falls while MC < AC, rises while MC > AC.
- **MR = MC holds where total profit is at its maximum** (not where TR = TC, which is break-even).
- **Quadratic shortcut:** y = ax^2 + bx + c has its turning point at x = −b/(2a) (maximum if a < 0).

**Explain more**

- **Cost (C = 300x − 10x^2 + (1/3)x^3):** MC = x^2 − 20x + 300; d(MC)/dx = 2x − 20 = 0 gives **x = 10** (minimum MC, second derivative 2 > 0). AC = C/x = (1/3)x^2 − 10x + 300; d(AC)/dx = (2/3)x − 10 = 0 gives **x = 15** (minimum AC). AC = MC: (1/3)x^2 − 10x + 300 = x^2 − 20x + 300, so 10x = (2/3)x^2, giving x = 15 or x = 0. Reject x = 0, because average cost C/x is undefined at zero output, so the answer is **x = 15**.
- **Overheads (₦6,000 overheads, ₦5 per unit material, labour x^2/60):** C = 6,000 + 5x + x^2/60; AC = 6,000/x + 5 + x/60. d(AC)/dx = −6,000/x^2 + 1/60 = 0, x^2 = 360,000, **x = 600**; AC = 10 + 5 + 10 = **₦25**.
- **Minimum total cost (C = x^3 − 195x^2 + 6,600x + 15,000):** C′ = 3x^2 − 390x + 6,600 = 3(x − 20)(x − 110) = 0. C″ = 6x − 390: C″(110) = 270 > 0, so **110** is the minimum (x = 20 is a maximum).
- **Revenue from demand:** p = (80 − x)/4, so R = (80x − x^2)/4; MR = 20 − x/2 = 0, **x = 40**, R = (3,200 − 1,600)/4 = **₦400**. If x is given in terms of p, rewrite p first (x = 70 − 5p: p = 14 − x/5), or maximise R = p·x in p (x = 100 − 5p: R = 100p − 5p^2, p = ₦10). For Q = 40 − P: R = 40Q − Q^2, MR = 40 − 2Q = 0, so revenue is maximised at **Q = 20**; at a set price of ₦15, Q = 25, R = ₦375.
- **Bulk-discount orders:** ₦700 per set up to 60 sets, ₦10 less per set for each set above 60. For x > 60, price = 700 − 10(x − 60) = 1,300 − 10x; R = 1,300x − 10x^2; R′ = 1,300 − 20x = 0, **x = 65 sets**.
- **Profit (R = 600y − 8y^2, C = y^2 + 78y + 2,500):** P = 522y − 9y^2 − 2,500; P′ = 522 − 18y = 0, **y = 29**. If P′ = 0 has two roots, keep the one with P″ < 0.
- **Profit as a function of price:** lamps sell 3,000 at ₦6, 1,000 fewer per ₦1 rise, cost ₦4. Quantity = 3,000 − 1,000(x − 6) = 9,000 − 1,000x. P = (x − 4)(9,000 − 1,000x). P′ = (9,000 − 1,000x) − 1,000(x − 4) = 13,000 − 2,000x = 0, **x = ₦6.50**. In general P = (x − c)(a − x) peaks at x = (a + c)/2: (80 + 10)/2 = ₦45; (120 + 20)/2 = ₦70; 400(15 − x)(x − 2) peaks at (15 + 2)/2 = ₦8.50.
- **Quotient rule profit:** P = 8,000x/(500 + x) − x. P′ = 8,000·500/(500 + x)^2 − 1 = 0, so (500 + x)^2 = 4,000,000, 500 + x = 2,000, **x = 1,500**; P = 6,000 − 1,500 = **4,500**.
- **Root demand:** q = 8,100/p^2 gives p = 90/sqrt(q). R = 90 sqrt(q); P = 90 sqrt(q) − 5q − 120; P′ = 45/sqrt(q) − 5 = 0, sqrt(q) = 9, **q = 81**, **p = 90/9 = ₦10**.
- **From marginal functions:** MR = 150 − x, MC = 0.1x^2 − 4x + 110. MR = MC: x^2 − 30x − 400 = 0, (x − 40)(x + 10) = 0, **x = 40** (P″ = 3 − 0.2x = −5 < 0).
- **Minimum cost route:** C(x) = 4(3,000 − x) + 5 sqrt(810,000 + x^2). C′ = −4 + 5x/sqrt(810,000 + x^2) = 0; 25x^2 = 16(810,000 + x^2); 9x^2 = 12,960,000; **x = 1,200 m**.
- **Profit per unit** = maximum profit ÷ units. P = −x^3/3 + 729x + 2,700: P′ = 729 − x^2 = 0, x = 27, P = 15,822, so ₦586 per unit.

### Lesson 4.3: Monopoly, price discrimination and Cournot duopoly

**Must know**

- **Monopolist:** faces the whole demand curve; maximise P = TR − TC with **MR = MC**, then read price from the demand curve.
- **Price discrimination (two markets, common MC):** set **MR1 = MC and MR2 = MC** separately; price higher in the less elastic market.
- **No discrimination:** add the two demands in Q form to get total Q in terms of one price P, then MR = MC.
- **Cournot duopoly:** each firm maximises its own profit taking the rival's output as given. Set ∂π1/∂q1 = 0 and ∂π2/∂q2 = 0 (reaction functions), solve together.
- **Shortcut** for P = a − q1 − q2 with constant MCs c1, c2: q1 = (a − 2c1 + c2)/3; q2 = (a − 2c2 + c1)/3.

**Explain more**

- **Monopoly (P = 70 − 2q, C = 10 + 30q):** TR = 70q − 2q^2, MR = 70 − 4q, MC = 30. 70 − 4q = 30, **q = 10**; **P = 70 − 20 = ₦50**; TR = 50 × 10 = **₦500**; TC = 10 + 300 = **₦310**; profit = **₦190**.
- **Two roots of MR = MC:** R = 1,000Q − 2Q^2, C = Q^3 − 59Q^2 + 1,315Q + 2,000. MR = 1,000 − 4Q; MC = 3Q^2 − 118Q + 1,315. Equate: 3Q^2 − 114Q + 315 = 0, Q^2 − 38Q + 105 = 0, **Q = 3 or 35**. P″ = −4 − (6Q − 118): at 3 it is +96 (minimum profit), at 35 it is −96 (maximum profit).
- **Revenue vs profit (P + 2Q = 20, TC = Q^3 − 8Q^2 + 20Q + 2):** TR = 20Q − 2Q^2 peaks at Q = 5. Profit = −Q^3 + 6Q^2 − 2; P′ = −3Q^2 + 12Q = 0, Q = 4; profit = **30**. MR = 0 always marks maximum TR (P + Q = 100: Q = 50, TR = 2,500).
- **Average-cost form (x = 480 − 20p, AC = 10 + x/15):** p = 24 − x/20; TR = 24x − x^2/20; TC = x·AC = 10x + x^2/15. P′ = 14 − x/10 − 2x/15 = 14 − 7x/30 = 0, **x = 60**, **p = 24 − 3 = ₦21**.
- **Price discrimination (P1 = 50 − 5Q1, P2 = 30 − 4Q2, TC = 10 + 10Q):** MC = 10. MR1 = 50 − 10Q1 = 10, Q1 = 4, **P1 = ₦30**. MR2 = 30 − 8Q2 = 10, Q2 = 2.5, **P2 = ₦20**. Profit = 120 + 50 − (10 + 65) = ₦95.
- **Same market, no discrimination:** Q1 = 10 − 0.2P, Q2 = 7.5 − 0.25P; Q = 17.5 − 0.45P, so P = (17.5 − Q)/0.45. MR = (17.5 − 2Q)/0.45 = 10, Q = 6.5; **P = 11/0.45 = ₦24.44**; profit = (11/0.45) × 6.5 − 75 = **₦83.89** (2 d.p.), less than ₦95.
- **Cournot (P = 40 − q1 − q2, TC1 = 6q1, TC2 = 8q2):** π1 = (40 − q1 − q2)q1 − 6q1; ∂π1/∂q1 = 34 − 2q1 − q2 = 0. π2 = (40 − q1 − q2)q2 − 8q2; ∂π2/∂q2 = 32 − q1 − 2q2 = 0. Solve: **q1 = 12, q2 = 10**; **P = 40 − 22 = ₦18**; π1 = (18 − 6)12 = **₦144**; π2 = (18 − 8)10 = **₦100**; together **₦244**; revenue of firm II = 18 × 10 = **₦180**.
- **Shortcut check (P = 20 − q1 − q2, c1 = 4, c2 = 6):** q1 = (20 − 8 + 6)/3 = 6, q2 = (20 − 12 + 4)/3 = 4, P = ₦10, π1 = ₦36, π2 = ₦16.

### Lesson 4.4: Functions of two variables and marginal analysis

**Must know**

- **Partial derivative f\_x (∂f/∂x):** differentiate in x, treating y as a constant; f\_y likewise.
- **Second order:** f\_xx, f\_yy, f\_xy = (f\_x)\_y, f\_yx; for ordinary functions **f\_xy = f\_yx**.
- **Marginal product:** Q\_K, Q\_L ≈ extra output from one more unit of K or L. **Q\_LL < 0** means diminishing marginal product of labour: with capital fixed, one more worker-hour adds less output when the labour force is large.
- **Total differential:** ΔQ ≈ Q\_x·Δx + Q\_y·Δy. **Percentage change** ≈ 100·ΔQ/Q.
- **Power functions:** if Q = A·K^a·L^b, % change in Q ≈ a(% change in K) + b(% change in L). Cobb-Douglas Q = A·K^α·L^(1−α) has **constant returns**: raise both inputs by 1% and Q rises 1%; double both and Q doubles.
- **Chain rule:** if x, y depend on t, dz/dt = z\_x·(dx/dt) + z\_y·(dy/dt).
- **Level curves (f constant):** dy/dx = −f\_x/f\_y; to keep output fixed, Δy ≈ −(f\_x/f\_y)Δx.
- **Exact change** = new value − old value (not the derivative estimate).

**Explain more**

- **Evaluate:** f(x, y) = 3x + y^2: f(2, 3) = 6 + 9 = 15; f(2, sqrt 2) = 6 + 2 = 8. Q = 500x^0.3 y^0.7 at (300, 50) is about 42,794; at (600, 100) it is 85,588 (exactly doubles, since 0.3 + 0.7 = 1).
- **Partials:** f = 4x^2 − 3xy + 5y^2 gives f\_x = 8x − 3y, f\_y = −3x + 10y. f = 2x^2 + 3x + y^2: dy/dx = −(4x + 3)/(2y). Watch the minus sign: −(−15x^4)/(12y^2 + 6) = +15x^4/(12y^2 + 6).
- **Product and chain inside:** f = x·e^(xy) + y^2. f\_x = e^(xy) + xy·e^(xy); at (1, 2) = e^2 + 2e^2 = **3e^2**. f\_y = x^2·e^(xy) + 2y; at (1, 2) = **e^2 + 4**.
- **Second order:** f = xy^3 + 5xy^2 + 2x + 1: f\_x = y^3 + 5y^2 + 2, **f\_xx = 0**, **f\_xy = f\_yx = 3y^2 + 10y**; f\_y = 3xy^2 + 10xy, **f\_yy = 6xy + 10x**. For f = ln(x^2 + 4y): f\_x = 2x/(x^2 + 4y); quotient rule gives f\_xx = (8y − 2x^2)/(x^2 + 4y)^2; at (2, 1/2): (4 − 8)/36 = **−1/9**.
- **Marginal products:** Q = 2,000x^0.5 y^0.5 at x = 16, y = 144: Q\_x = 1,000·sqrt(y/x) = 1,000 × 3 = **3,000**; Q\_y = 1,000·sqrt(x/y) = **333.33**.
- **Capital in ₦1,000 units (Q = 60K^(1/2)L^(1/3), K = 900, L = 1,000):** Q\_K = 30K^(−1/2)L^(1/3) = 30 × (1/30) × 10 = **10** units per extra ₦1,000. Q\_L = 20K^(1/2)L^(−2/3) = 20 × 30/100 = 6. Adding ₦1,000 and 2 worker-hours: ΔQ ≈ 10(1) + 6(2) = **22**.
- **Percentages:** Q = 600K^(1/2)L^(1/3), labour +2%: (1/3)(2) = **0.67%**. V = πr^2h, r +1%, h +2%: 2(1) + 1(2) = **4%**.
- **Total differential:** Q = 0.08x^2 + 0.12xy + 0.03y^2 at (80, 200): Q\_x = 0.16x + 0.12y = 36.8; Q\_y = 0.12x + 0.06y = 21.6. ΔQ ≈ 36.8(0.5) + 21.6(2) = **61.6**.
- **Chain rule:** z = x^2 + 3xy, x = 2t + 1, y = t^2. dz/dt = (2x + 3y)(2) + (3x)(2t) = 2(3t^2 + 4t + 2) + 6t(2t + 1) = **18t^2 + 14t + 4**. Demand Q = 300 − 20x^2 + 30y with x = 2 + 0.05t, y = 2 + 0.1 sqrt(t), at t = 4: x = y = 2.2; dQ/dt = (−40x)(0.05) + 30(0.05/sqrt t) = −4.4 + 0.75 = **−3.65** (decreasing).
- **Offsetting change:** f = 10x·y^(1/2) at (30, 36): f\_x = 10 sqrt(y) = 60; f\_y = 5x/sqrt(y) = 25. Δy ≈ −(60/25)(1) = **−2.4 hours**. Utility (x + 1)(y + 2) at (25, 8): U\_x = 10, U\_y = 26; giving up 1 unit of y needs Δx ≈ 26/10 = **2.6 units**.
- **Exact vs estimate:** Q = 10x^2y at (20, 40) = 160,000. Q(21, 40) = 176,400, change **16,400**; Q(21, 41) = 180,810, change **20,810**.

### Lesson 4.5: Two-variable optimisation and Lagrange multipliers

**Must know**

- **Unconstrained steps:** (1) solve f\_x = 0 and f\_y = 0 together; (2) compute **D = f\_xx·f\_yy − (f\_xy)^2** at the point.

| D and f\_xx | Conclusion |
|---|---|
| D > 0, f\_xx < 0 | relative maximum |
| D > 0, f\_xx > 0 | relative minimum |
| D < 0 | saddle point |
| D = 0 | inconclusive |

- **Lagrange method** (optimise f(x, y) subject to g(x, y) = k): form F = f(x, y) − λ[g(x, y) − k]; solve F\_x = 0, F\_y = 0, F\_λ = 0, i.e. **f\_x = λg\_x, f\_y = λg\_y, g = k**. Then put x, y into f.
- **Meaning of λ:** λ = dM/dk, the approximate change in the optimal value M when the constraint (budget) rises by 1 unit. ΔM ≈ λ·Δk.
- **Cobb-Douglas shortcut:** maximise A·x^a·y^b (or a·ln x + b·ln y) subject to p1x + p2y = B: spend a/(a + b) of B on x and b/(a + b) on y.

**Explain more**

- **Minimum (f = x^2 − xy + y^2 − 9x + 5):** f\_x = 2x − y − 9 = 0; f\_y = −x + 2y = 0, so x = 2y; 3y = 9, y = 3, x = 6. D = 2·2 − (−1)^2 = 3 > 0, f\_xx = 2 > 0: **relative minimum at (6, 3)**, f = 36 − 18 + 9 − 54 + 5 = **−22**. f = x^2 + y^2: D = 4, minimum at (0, 0); f = y^2 − x^2: D = −4, **saddle point**.
- **Profit (P = 412x + 806y − x^2 − 4y^2 − xy − 50,000):** P\_x = 412 − 2x − y = 0; P\_y = 806 − x − 8y = 0. y = 412 − 2x, so 806 − x − 3,296 + 16x = 0, **x = 166, y = 80**. D = (−2)(−8) − 1 = 15 > 0, maximum. P = 68,392 + 64,480 − 27,556 − 25,600 − 13,280 − 50,000 = **16,436**.
- **Two products (umbrellas at ₦20 and ₦25, cost C in ₦ thousands):** P = 20x + 25y − C. P\_x = −6x + 3y − 12 = 0; P\_y = 3x − 3y + 54 = 0. Add: −3x + 42 = 0, **x = 14, y = 32** (14,000 and 32,000). P = 280 + 800 − 370 = 710, i.e. **₦710,000**.
- **Two prices:** P = (x − 30)(70 − 5x + 4y) + (y − 40)(80 + 6x − 7y). P\_x = −10x + 10y − 20; P\_y = 10x − 14y + 240. Then y = x + 2 and −4x + 212 = 0: **x = ₦53, y = ₦55**. At (50, 52): P\_x = 0, P\_y = 12, so +₦1 on the second brand adds about ₦12; +₦1 and +₦2 adds 0 + 24 = ₦24.
- **Separate terms:** profit = 100[320y/(y + 2) + 160x/(x + 4)] − 1,000(x + y) naira. P\_x = 64,000/(x + 4)^2 − 1,000 = 0, (x + 4)^2 = 64, x = 4; P\_y = 64,000/(y + 2)^2 − 1,000 = 0, y = 6: **₦4,000 development, ₦6,000 promotion**.
- **Lagrange (f = 20x^(3/2)y, x + y = 60, ₦ thousands):** 30x^(1/2)y = λ and 20x^(3/2) = λ. Equate: 30y = 20x, y = 2x/3; x + 2x/3 = 60, **x = 36, y = 24** (₦36,000 and ₦24,000). f = 20 × 216 × 24 = **103,680 copies**. λ = 20 × 36^(3/2) = 4,320; budget up by 0.2 thousand: ΔM ≈ 4,320 × 0.2 = **864 copies**.
- **Shortcut uses:** 16L^0.25K^0.75, ₦50 and ₦100, ₦500,000: labour gets 1/4 = ₦125,000, **L = 2,500**; capital ₦375,000, **K = 3,750**. U = 10x^0.6y^0.4, ₦20 and ₦30, ₦600: **x = 360/20 = 18, y = 240/30 = 8**; λ = U\_x/20 = 0.3(8/18)^0.4 ≈ **0.22** per extra ₦1. Q = 5 ln X + 6 ln Y, ₦8 and ₦16, ₦352,000: X = (5/11)(352,000)/8 = **20,000**, Y = (6/11)(352,000)/16 = **12,000**, Q = 5 ln 20,000 + 6 ln 12,000 = **105.873**.
- **Substitution method:** max 4x − x^3 + 2y with x + y = 1: y = 1 − x, f = 2 + 2x − x^3; f′ = 2 − 3x^2 = 0, x = sqrt(2/3) = 0.8165, y = 0.1835, f = **3.0887** (4 d.p.). 10x + 4y − 2x^2 − y^2 with 2x + y = 5: 10 − 4x = 2λ, 4 − 2y = λ give x = y + 1/2; x = 11/6, y = 4/3, maximum **91/6**. xy with x^2 + y^2 = 8: y = 2λx, x = 2λy give x^2 = y^2 = 4; **maximum 4, minimum −4**. 3x^2 + 5xy − 6y^2 + 26x + 12y with 3x + y = 170: 6x + 5y + 26 = 3λ, 5x − 12y + 12 = λ; eliminate λ: 9x = 41y − 10; with the constraint, y = 130/11 = 11.82, x = 580/11 = 52.73, f = **12,130.91**.

### Lesson 4.6: Exponential growth and decay models

**Must know**

- **Exponential growth:** Q(t) = Q0·e^(kt), k > 0 (continuous rate); **decay:** Q(t) = Q0·e^(−kt). Discrete version: Q = Q0(1 + r)^t.
- **Rate of change:** dQ/dt = kQ, so the **percentage rate of change** = 100·Q′/Q = 100k (constant).
- **Percentage rate of change** of any f: 100·f′(t)/f(t).
- **Doubling time** = ln 2/k; **half-life** = ln 2/k (ln 2 ≈ 0.6931).
- **Learning curve:** Q = B − A·e^(−kt) rises towards the ceiling B; Q′ = kA·e^(−kt) > 0 but falls over time.

**Explain more**

- **Growth:** a Lagos suburb of 2 million grows at 3% continuously: Q(5) = 2e^(0.15) = **2.324 million** (3 d.p.). Doubling time = 0.6931/0.03 = **23.1 years**.
- **Decay:** V = 500,000e^(−0.1t) for a ₦500,000 machine: V(5) = 500,000e^(−0.5) = **₦303,265** (nearest naira); half-life 6.93 years.
- **Percentage rate:** GNP N(t) = t^2 + 5t + 106: at t = 10, N′ = 2(10) + 5 = 25, N = 256, rate = 100 × 25/256 = **9.77%**.
- **Learning curve:** Q = 120 − 80e^(−0.2t) units a day after t weeks: Q(5) = 120 − 80e^(−1) = **90.57** units; output can never pass 120.

### One-minute recap

- Stationary point f′ = 0; f″ < 0 maximum, f″ > 0 minimum, f″ = 0 use sign of f′.
- Inflection = concavity change; point of diminishing returns = inflection of sales/output.
- Min AC: d(AC)/dx = 0, where AC = MC. Max revenue: MR = 0. Max profit: MR = MC with P″ < 0.
- Price discrimination: MR in each market = MC. Cournot: solve both reaction functions; q1 = (a − 2c1 + c2)/3.
- Partials hold the other variable constant; ΔQ ≈ Q\_xΔx + Q\_yΔy; dy/dx = −f\_x/f\_y.
- Cobb-Douglas with exponents summing to 1: constant returns.
- Two variables: D = f\_xx·f\_yy − (f\_xy)^2; D < 0 saddle.
- Lagrange: f\_x = λg\_x, f\_y = λg\_y, g = k; λ = change in optimum per unit of budget.
- Growth Q0e^(kt): percentage rate 100k, doubling time ln 2/k.

### Theory practice

**Question:** Find and classify the stationary point of f(x, y) = 2x^2 + y^2 − 4x + 6y + 15, and give the value of f there.

*Answer:* f\_x = 4x − 4 = 0, so x = 1. f\_y = 2y + 6 = 0, so y = −3. f\_xx = 4, f\_yy = 2, f\_xy = 0, D = 4 × 2 − 0 = 8 > 0 and f\_xx > 0: relative minimum at (1, −3). f(1, −3) = 2 + 9 − 4 − 18 + 15 = 4.
