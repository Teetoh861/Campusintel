## Topic 1: Integral Calculus Applications

**What you must know:** integration as the reverse of differentiation and its basic rules; substitution; integration by parts; partial fractions; definite integrals and areas; total cost, revenue, profit and demand from marginal functions; consumer's and producer's surplus; total sales, income streams and continuous annuities.

### Lesson 1.1: Integration as anti-differentiation: the basic rules

**Must know**

- **Integral (anti-derivative):** if d/dx F(x) = f(x), then F(x) is an integral of f(x), written F(x) = ∫ f(x) dx. f(x) is the **integrand**; finding F is **integration**. Integration is the reverse process of differentiation.
- **Indefinite integral:** ∫ f(x) dx = F(x) + c. The **constant of integration c** appears because the derivative of any constant is 0 (x^3, x^3 + 2 and x^3 + c all differentiate to 3x^2).
- **Two properties (direct integration):**
  1. ∫ k·f(x) dx = k·∫ f(x) dx (a constant factor comes outside).
  2. ∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx (integrate term by term).

| Integrand | Integral (add + c) |
|---|---|
| k (constant) | kx |
| x^n (n ≠ −1) | x^(n+1)/(n + 1) |
| 1/x = x^(−1) | ln x (x > 0) |
| e^x | e^x |
| e^(mx) | e^(mx)/m |
| a^x (a > 0, a ≠ 1) | a^x/ln a |
| a^(mx) | a^(mx)/(m·ln a) |

- **Power rule in words:** add 1 to the power, then divide by the new power. It fails only for n = −1, which gives ln x.
- **Check any answer** by differentiating it.

**Explain more**

Rewrite roots and fractions as powers first: sqrt(x) = x^(1/2), 1/x^3 = x^(−3), 1/sqrt(x) = x^(−1/2).

- ∫ 10x^5 dx = 10·x^6/6 + c = (5/3)x^6 + c. (Trap: 2x^6 forgets to divide properly; 50x^4 is the derivative.)
- ∫ (x^5 + 3x^2 − 5x) dx = (1/6)x^6 + x^3 − (5/2)x^2 + c.
- ∫ x^10 dx = x^11/11 + c; ∫ x^(1/2) dx = x^(3/2)/(3/2) = (2/3)x^(3/2) + c.
- ∫ 1/x^3 dx = ∫ x^(−3) dx = x^(−2)/(−2) = −1/(2x^2) + c.
- ∫ (3x^(−1) + 4x^2 − 3x + 8) dx = 3 ln x + (4/3)x^3 − (3/2)x^2 + 8x + c.
- ∫ (2 sqrt(x) + 5x^(−1) + 3x^2) dx = 2·(2/3)x^(3/2) + 5 ln x + x^3 = (4/3)x^(3/2) + 5 ln x + x^3 + c.
- ∫ (1/x^2 − 1/x^3) dx = −1/x + 1/(2x^2) + c; ∫ (sqrt(x) + x^(1/3)) dx = (2/3)x^(3/2) + (3/4)x^(4/3) + c.
- ∫ (sqrt(x) − x/2 + 2/sqrt(x)) dx = (2/3)x^(3/2) − x^2/4 + 4 sqrt(x) + c.

**Products and quotients: expand or divide first.** Never integrate each bracket separately.
- ∫ (1 + x)(1 − 3x) dx = ∫ (1 − 2x − 3x^2) dx = x − x^2 − x^3 + c.
- ∫ (1 + x)(1 + 2x) dx = ∫ (1 + 3x + 2x^2) dx = x + 3x^2/2 + 2x^3/3 + c.
- ∫ (x^2 − 1)^2 dx = ∫ (x^4 − 2x^2 + 1) dx = x^5/5 − 2x^3/3 + x + c.
- ∫ (x + sqrt(x))^2 dx = ∫ (x^2 + 2x^(3/2) + x) dx = x^3/3 + 4x^(5/2)/5 + x^2/2 + c.
- ∫ (x − 1/x)^3 dx = ∫ (x^3 − 3x + 3/x − x^(−3)) dx = x^4/4 − 3x^2/2 + 3 ln x + 1/(2x^2) + c.
- ∫ (x^4 + 1)/x^2 dx = ∫ (x^2 + x^(−2)) dx = x^3/3 − 1/x + c.
- ∫ (x^2 + 1)x dx = ∫ (x^3 + x) dx = x^4/4 + x^2/2 + c, which equals (1/4)(x^2 + 1)^2 + c (they differ only by the constant 1/4).

**Exponentials and constants.**
- ∫ (3x^2 + e^x + a^x) dx = x^3 + e^x + a^x/ln a + c. (Trap: a^x·ln a is the derivative, not the integral.)
- ∫ (3x^5 + e^((n+1)x) + a^(5x)) dx = x^6/2 + e^((n+1)x)/(n + 1) + a^(5x)/(5 ln a) + c.
- ∫ (2^x + (1/2)e^(−x) + 4/x − x^(−1/3)) dx = 2^x/ln 2 − (1/2)e^(−x) + 4 ln x − (3/2)x^(2/3) + c.
- ∫ (x^(1/3) + e^3) dx = (3/4)x^(4/3) + e^3·x + c. e^3 is a number, so it integrates like any constant k.

### Lesson 1.2: Integration by substitution

**Must know**

- **Method:** choose u = the "inner" expression; find du = u'(x) dx; rewrite the whole integral in u; integrate; put x back.
- **Linear inside (ax + b), a ≠ 0:** integrate as usual, then divide by a.
  1. ∫ (ax + b)^n dx = (ax + b)^(n+1)/[a(n + 1)] + c, n ≠ −1.
  2. ∫ 1/(ax + b) dx = (1/a) ln(ax + b) + c.
  3. ∫ e^(ax + b) dx = (1/a) e^(ax + b) + c.
- **Log pattern:** ∫ f'(x)/f(x) dx = ln f(x) + c (top is the derivative of the bottom).
- **Power pattern:** ∫ f'(x)·[f(x)]^n dx = [f(x)]^(n+1)/(n + 1) + c, n ≠ −1.
- If the top is only a **constant multiple** of f'(x), adjust by that constant.

**Explain more**

**Linear inside.**
- ∫ (2x + 3)^5 dx: u = 2x + 3, du = 2 dx, so (1/2)∫ u^5 du = u^6/12 = (1/12)(2x + 3)^6 + c.
- ∫ dx/(5x − 6)^3: u = 5x − 6, du = 5 dx: (1/5)∫ u^(−3) du = (1/5)·u^(−2)/(−2) = −1/(10(5x − 6)^2) + c.
- ∫ dw/(7 − 2w)^3: u = 7 − 2w, du = −2 dw: (−1/2)·u^(−2)/(−2) = +1/(4(7 − 2w)^2) + c. (The negative a turns the sign positive; watch this.)
- ∫ (5 − 2x)^(−3/2) dx: (−1/2)·u^(−1/2)/(−1/2) = u^(−1/2) = 1/sqrt(5 − 2x) + c.
- ∫ dx/(1 − 4x) = −(1/4) ln(1 − 4x) + c; ∫ e^(2x − 1) dx = (1/2)e^(2x − 1) + c.

**Log pattern.**
- ∫ (3x^2 + 2)/(x^3 + 2x + 5) dx = ln(x^3 + 2x + 5) + c, since the top is exactly the derivative of the bottom.
- ∫ (4x^3 + 2x)/(x^4 + x^2 + 2) dx = ln(x^4 + x^2 + 2) + c.
- ∫ x/(2x^2 + 3) dx: derivative of the bottom is 4x, so = (1/4) ln(2x^2 + 3) + c.
- ∫ 1/(e^x + 1) dx: multiply top and bottom by e^(−x) to get ∫ e^(−x)/(1 + e^(−x)) dx. The derivative of 1 + e^(−x) is −e^(−x), so the answer is −ln(1 + e^(−x)) + c.

**Power pattern.**
- ∫ x^2(2x^3 + 3)^5 dx: u = 2x^3 + 3, du = 6x^2 dx: (1/6)∫ u^5 du = (1/36)(2x^3 + 3)^6 + c.
- ∫ x/sqrt(1 + x^2) dx: u = 1 + x^2, du = 2x dx: (1/2)∫ u^(−1/2) du = u^(1/2) = sqrt(1 + x^2) + c.
- ∫ 8x^2/(x^3 + 2)^3 dx: u = x^3 + 2, du = 3x^2 dx: (8/3)∫ u^(−3) du = (8/3)(−1/(2u^2)) = −4/(3(x^3 + 2)^2) + c.
- ∫ (ax^2 + 2bx + 2c)^5 (ax + b) dx: du = (2ax + 2b) dx = 2(ax + b) dx, so (1/2)·u^6/6 = (ax^2 + 2bx + 2c)^6/12 + K.
- ∫ (1/x) ln x dx: u = ln x, du = dx/x: ∫ u du = (1/2)(ln x)^2 + c.
- ∫ 1/(x(1 + ln x)^3) dx: u = 1 + ln x: ∫ u^(−3) du = −1/(2(1 + ln x)^2) + c.
- ∫ e^(sqrt(x + 1))/sqrt(x + 1) dx: u = sqrt(x + 1), du = dx/(2 sqrt(x + 1)): 2∫ e^u du = 2e^(sqrt(x + 1)) + c.

Substitution can leave ∫ ln u du (Lesson 1.3): ∫ (1/x) ln(ln x) dx = (ln x)[ln(ln x) − 1] + c, and ∫ 2x ln(a + x^2) dx = (a + x^2)[ln(a + x^2) − 1] + c.

### Lesson 1.3: Integration by parts and partial fractions

**Must know**

- **Integration by parts:** ∫ u dv = uv − ∫ v du (equivalently ∫ u·v' dx = u·v − ∫ v·u' dx).
- **Choosing u:** take u = ln x whenever ln x appears; otherwise take u = the power of x (x, x^2) and dv = the exponential.
- **Standard results:**
  1. ∫ ln x dx = x ln x − x + c
  2. ∫ x e^x dx = e^x(x − 1) + c
  3. ∫ x e^(−x) dx = −e^(−x)(x + 1) + c
  4. ∫ x^n ln x dx = [x^(n+1)/(n + 1)] ln x − x^(n+1)/(n + 1)^2 + c, n ≠ −1
  5. ∫ x^2 e^(kx) dx = e^(kx)[x^2/k − 2x/k^2 + 2/k^3] + c (parts used twice)
- **Partial fractions** (use when substitution fails on a fraction):
  1. If the degree of the top ≥ the degree of the bottom, **divide first** (this produces the extra "x" term).
  2. Split: (px + q)/((x − α)(x − β)) = A/(x − α) + B/(x − β).
  3. Find A and B by putting x = α, then x = β (cover-up).
  4. Integrate each part with ∫ 1/(ax + b) dx = (1/a) ln(ax + b).

**Explain more**

**By parts, step by step.**
- ∫ x e^x dx: u = x, dv = e^x dx, so du = dx, v = e^x. Then x e^x − ∫ e^x dx = x e^x − e^x = e^x(x − 1) + c.
- ∫ ln x dx: u = ln x, dv = dx, du = dx/x, v = x. Then x ln x − ∫ 1 dx = x ln x − x + c.
- ∫ x ln x dx: u = ln x, v = x^2/2: (x^2/2) ln x − ∫ (x/2) dx = (1/2)x^2 ln x − (1/4)x^2 + c.
- ∫ x^2 ln x dx: u = ln x, v = x^3/3: (x^3/3) ln x − ∫ x^2/3 dx = (x^3/3) ln x − x^3/9 = (x^3/9)(3 ln x − 1) + c.
- ∫ x e^(−x) dx: u = x, v = −e^(−x): −x e^(−x) + ∫ e^(−x) dx = −x e^(−x) − e^(−x) = −e^(−x)(x + 1) + c.
- Using result 5: ∫ x^2 e^x dx = e^x(x^2 − 2x + 2) + c (k = 1); ∫ x^2 e^(2x) dx = e^(2x)[x^2/2 − x/2 + 1/4] = (1/2)e^(2x)(x^2 − x + 1/2) + c (k = 2); ∫ x^2 e^(3x) dx = x^2e^(3x)/3 − 2xe^(3x)/9 + 2e^(3x)/27 + c (k = 3). The signs alternate +, −, +.

**Partial fractions.**
- ∫ (3x + 2)/((1 + x)(1 + 2x)) dx. Write 3x + 2 = A(1 + 2x) + B(1 + x). x = −1: −1 = −A, so A = 1. x = −1/2: 1/2 = B/2, so B = 1. Answer: ln(1 + x) + (1/2) ln(1 + 2x) + c.
- ∫ 1/((x + 1)(x + 3)) dx: A = 1/2, B = −1/2, giving (1/2)[ln(x + 1) − ln(x + 3)] + c.
- ∫ (x + 2)/(x^2 − 13x + 42) dx: factor x^2 − 13x + 42 = (x − 7)(x − 6). x = 7: A = 9/1 = 9. x = 6: B = 8/(−1) = −8. Answer: 9 ln(x − 7) − 8 ln(x − 6) + c.
- ∫ x/((x − 1)(2x + 1)) dx: A = 1/3, B = (−1/2)/(−3/2) = 1/3. Answer: (1/3) ln(x − 1) + (1/6) ln(2x + 1) = (1/6)[2 ln(x − 1) + ln(2x + 1)] + c.
- ∫ 1/(x − x^3) dx: x − x^3 = x(1 − x)(1 + x); A/x + B/(1 − x) + C/(1 + x) gives A = 1, B = 1/2, C = −1/2. Integral = ln x − (1/2) ln(1 − x) − (1/2) ln(1 + x) = (1/2) ln(x^2/(1 − x^2)) + c.
- Improper fractions: x^2/((x − a)(x − b)) = 1 + A/(x − a) + B/(x − b), A = a^2/(a − b), B = b^2/(b − a). Answer: x + [a^2/(a − b)] ln(x − a) − [b^2/(a − b)] ln(x − b) + c. In the same way, ∫ x^3/((x − a)(x − b)(x − c)) dx = x + a^3 ln(x − a)/((a − b)(a − c)) + b^3 ln(x − b)/((b − a)(b − c)) + c^3 ln(x − c)/((c − a)(c − b)) + k. Forgetting the leading x is the usual trap.

### Lesson 1.4: Definite integrals and areas

**Must know**

- **Definite integral:** ∫ from a to b of f(x) dx = [F(x)] from a to b = F(b) − F(a), where F is any anti-derivative. a is the **lower limit**, b the **upper limit**.
- **The constant disappears:** [F(b) + c] − [F(a) + c] = F(b) − F(a).
- **Properties:**
  1. ∫ from a to a of f(x) dx = 0.
  2. ∫ from a to b = −∫ from b to a (swapping limits changes the sign).
  3. ∫ from a to b = ∫ from a to c + ∫ from c to b.
  4. Odd function (f(−x) = −f(x)): ∫ from −a to a = 0.
  5. Even function (f(−x) = f(x)): ∫ from −a to a = 2∫ from 0 to a.
- **Area under a curve** (f(x) ≥ 0 on [a, b]) = ∫ from a to b of f(x) dx.
- **Area bounded by a curve and the x-axis:** find where f(x) = 0; integrate between those roots.
- **Area between two curves:** solve f(x) = h(x) for the meeting points; area = ∫ (upper − lower) dx between them. Where the curves cross, split the interval and add the **sizes** of the pieces.
- **Improper case:** ∫ from 0 to 5 of (1/y) dy has **no finite value**, because ln y has no finite value as y approaches 0.

**Explain more**

- ∫ from 2 to 3 of x^3 dx = [x^4/4] = 81/4 − 16/4 = 65/4.
- ∫ from 1 to 3 of x^2 dx = 27/3 − 1/3 = 26/3.
- ∫ from 2 to 4 of (7x^3 + x) dx = [7x^4/4 + x^2/2] = (448 + 8) − (28 + 2) = 426.
- ∫ from 1 to 2 of (x^(−2) + x) dx = [−1/x + x^2/2] = (−1/2 + 2) − (−1 + 1/2) = 2.
- ∫ from 6 to 10 of 1/(x + 2) dx = ln 12 − ln 8 = ln(3/2).
- ∫ from −1 to 3 of 4/(2x + 3) dx = 2[ln(2x + 3)] = 2(ln 9 − ln 1) = 4.3944 (4 d.p.).
- ∫ from 2 to 3 of e^(3x) dx = (1/3)(e^9 − e^6); ∫ from 2 to 3 of e^(2x) dx = (1/2)(e^6 − e^4) = (1/2)e^4(e^2 − 1).
- ∫ from 1 to 2 of (e^(2x) + 3x^2) dx = (1/2)(e^4 − e^2) + 7 = (1/2)(e^4 − e^2 + 14). Similarly ∫ from 1 to 2 of (e^(3x) + 4x^2) dx = (1/3)(e^6 − e^3) + 28/3 = (1/3)(e^6 − e^3 + 28).
- ∫ from 1 to 6 of 60/(3x + 2)^2 dx = [−20/(3x + 2)] = −20/20 + 20/5 = 3.
- ∫ from 1 to 3 of 2x/(1 + x^2) dx = ln 10 − ln 2 = ln 5; ∫ from 0 to 2 of x/(x^2 + 4) dx = (1/2)(ln 8 − ln 4) = (1/2) ln 2; ∫ from 0 to ln 2 of e^x/(1 + e^x) dx = ln 3 − ln 2 = ln 1.5.
- ∫ from 1 to 2 of 1/(x(x + 1)) dx = [ln x − ln(x + 1)] = (ln 2 − ln 3) − (0 − ln 2) = ln(4/3).
- ∫ from −2 to 2 of x^3 dx = 4 − 4 = 0 (x^3 is odd).

**Areas.**
- Area under f(x) = 3x^(1/2) − 2 from 4 to 16 = [2x^(3/2) − 2x] = (128 − 32) − (16 − 8) = 88 square units.
- Area under f(x) = x^(1/3) + 5 from 1 to 8 = [(3/4)x^(4/3) + 5x] = (12 + 40) − (3/4 + 5) = 185/4 square units.
- Curve f(x) = 16 − x^2 and the x-axis: roots x = ±4. Area = [16x − x^3/3] from −4 to 4 = 128/3 − (−128/3) = 256/3 square units.
- f(x) = 15 − 2x − x^2 and h(x) = 9 − x: 15 − 2x − x^2 = 9 − x gives x^2 + x − 6 = 0, so x = −3 or 2. Area = ∫ from −3 to 2 of (6 − x − x^2) dx = [6x − x^2/2 − x^3/3] = 22/3 − (−27/2) = 125/6 square units.
- f(x) = 3x^3 − 3x and h(x) = x meet at x = −2/sqrt(3), 0, 2/sqrt(3). f − h = 3x^3 − 4x. Each piece has size 4/3, so total area = 8/3 square units. (Trap: integrating straight across gives 0, because the pieces cancel.)

### Lesson 1.5: Total functions from marginal functions

**Must know**

- Marginal = derivative of the total, so **total = integral of the marginal**.
  1. **Total cost:** C(x) = ∫ MC dx + k. Fixed cost FC = C(0).
  2. **Average cost:** AC = C(x)/x, x ≠ 0.
  3. **Total revenue:** R(x) = ∫ MR dx + k, with k found from R(0) = 0 (no sales, no revenue) unless another point is given.
  4. **Demand (price) function:** p = R(x)/x = average revenue (AR = price).
  5. **Profit:** P(x) = R(x) − C(x); marginal profit = MR − MC.
- **Finding k:** substitute the given point (fixed cost, or a known cost/revenue at some x) into the integrated function. k equals the fixed cost only when C(0) has no other constant in it.
- **Change in total** when output rises from a to b = ∫ from a to b of (marginal) dx. No constant is needed.
- **Any rate:** if a quantity changes at rate f(t), the total change over [a, b] is ∫ from a to b of f(t) dt. Capital stock K = ∫ I dt (I = net investment); a curve with slope f'(x) is f(x) = ∫ f'(x) dx + c.

**Explain more**

**Finding the constant.**
- With a polynomial MC, k is simply the fixed cost: MC = 9x^2 + 4x − 20, FC = ₦1,000 gives C(x) = 3x^3 + 2x^2 − 20x + 1000; MC = 25 + 30Q − 9Q^2, FC = 55 gives TC = 25Q + 15Q^2 − 3Q^3 + 55; MC = 20 − 0.04x + 0.003x^2, FC = ₦7,000 gives C = 20x − 0.02x^2 + 0.001x^3 + 7000.
- An Aba shoe maker has MC = 6 + 10x − 6x^2 and producing a pair (x = 2) costs ₦12. C = 6x + 5x^2 − 2x^3 + k; 12 = 12 + 20 − 16 + k, so k = −4. C = 6x + 5x^2 − 2x^3 − 4 and AC = 6 + 5x − 2x^2 − 4/x.
- MC = 5 + 16x − 3x^2, C(5) = ₦500: C(5) = 25 + 200 − 125 + k = 100 + k, so k = 400. MC = 3x^2 − 10x + 3, C(1) = ₦7: −1 + k = 7, so k = 8. MC = 8x^3, C(1) = 5: 2 + k = 5, so C = 2x^4 + 3.
- **Exponential MC:** MC = 12e^(0.5Q), FC = 36: TC = 24e^(0.5Q) + k; at Q = 0, 24 + k = 36, so TC = 24e^(0.5Q) + 12. MC = 16e^(0.4Q), FC = 100: TC = 40e^(0.4Q) + 60. MC = 2 + 5e^x, C(0) = 100: C = 2x + 5e^x + 95 and AC = 2 + 5e^x/x + 95/x. Here k is **not** the fixed cost, because e^0 = 1.
- **Root MC:** MC = 3(2x + 25)^(1/2), FC = ₦11,125. C = 3·(2x + 25)^(3/2)/(3/2 × 2) + k = (2x + 25)^(3/2) + k. C(0) = 125 + k = 11,125, so k = 11,000. C(300) = 625^(3/2) + 11,000 = 15,625 + 11,000 = ₦26,625.
- MC = x/sqrt(x^2 + 2500), FC = ₦1,000: C = sqrt(x^2 + 2500) + k; 50 + k = 1000, so C = sqrt(x^2 + 2500) + 950.
- MC = 14000/sqrt(7x + 4), FC = ₦18,000: C = 4000 sqrt(7x + 4) + k; 8000 + k = 18,000, k = 10,000. C(3) = 4000 × 5 + 10,000 = ₦30,000; AC = 30,000/3 = ₦10,000.
- MC = x sqrt(x + 1), C(3) = ₦7,800: put u = x + 1, x = u − 1: ∫ (u^(3/2) − u^(1/2)) du gives C = (2/5)(x + 1)^(5/2) − (2/3)(x + 1)^(3/2) + k. At x = 3: 64/5 − 16/3 = 112/15, so k = 7800 − 112/15 = 116888/15.
- MC proportional to x (MC = kx), FC = ₦5,000, C(50) = ₦5,625: C = kx^2/2 + 5000; 1250k = 625, k = 1/2, so C = x^2/4 + 5000.
- MC in thousands: c'(x) = 4x^2 − 6x + 1, c(0) = 400. c(12) = (4/3)(1728) − 3(144) + 12 + 400 = 2304 − 432 + 12 + 400 = 2,284 thousand = ₦2,284,000.
- MC = 0.1x^2 − 4x + 110, C(30) = ₦4,000: ∫ from 0 to 30 = 900 − 1800 + 3300 = 2,400 is variable cost, so FC = 4,000 − 2,400 = ₦1,600.
- MC = 125 + 10x − x^2/9, FC = ₦250: C(15) = 1875 + 1125 − 125 + 250 = ₦3,125.

**Change between two outputs.**
- MC = 3q^2 − 60q + 400, first 2 units cost ₦900: ∫ from 2 to 5 = [q^3 − 30q^2 + 400q] = 1375 − 688 = 687, so C(5) = 900 + 687 = ₦1,587.
- MC = 2Q + 6, TC(8) = 212: ∫ from 8 to 14 = [Q^2 + 6Q] = 280 − 112 = 168, so TC(14) = 380.
- MR = 100 + 50x − 3x^2, 5 extra units after 5: ∫ from 5 to 10 = [100x + 25x^2 − x^3] = 2500 − 1000 = ₦1,500.
- MR = 275 − x − 0.3x^2, output from 10 to 20: [275x − x^2/2 − 0.1x^3] = 4500 − 2600 = ₦1,900.
- A firm with 200 workers makes 50,000 units a week; extra output per added worker is 300 − 5x^(2/3). For 64 more workers: ∫ from 0 to 64 = 300(64) − 3(64)^(5/3) = 19,200 − 3,072 = 16,128 additional units (66,128 in total; read which one is asked).

**Revenue and demand.**
- MR = 500 − 4x, R(0) = 0: R = 500x − 2x^2. MR = 60 − 2Q − 2Q^2: TR = 60Q − Q^2 − (2/3)Q^3.
- MR = 100 − 6Q: TR = 100Q − 3Q^2 and P = TR/Q = 100 − 3Q. MR = 20 − 2Q: TR = 20Q − Q^2, P = 20 − Q. MR = 6/sqrt(Q): TR = 12 sqrt(Q), P = 12/sqrt(Q).
- MR = 12 − 3x^2 + 4x: R = 12x + 2x^2 − x^3, p = 12 + 2x − x^2. MR = 20 − 5x + 3x^2: R = 20x − (5/2)x^2 + x^3. MR = 14 − 6x + 9x^2: p = 14 − 3x + 3x^2.
- MR = 5 + 3x − x^2, R(6) = 112: R = 5x + (3/2)x^2 − (1/3)x^3 + k; 30 + 54 − 72 + k = 112, k = 100. R = 100 + 5x + (3/2)x^2 − (1/3)x^3; AR = 100/x + 5 + (3/2)x − (1/3)x^2.

### Lesson 1.6: Surplus, sales, profitable life and income streams

**Must know**

- **Equilibrium (x0, p0):** where demand price = supply price.
- **Consumer's surplus (CS)** = ∫ from 0 to x0 of d(x) dx − x0·p0: what consumers were willing to pay minus what they actually pay.
- **Producer's surplus (PS)** = x0·p0 − ∫ from 0 to x0 of s(x) dx: what producers actually receive minus what they were willing to accept.
- If only a demand curve and a quantity x0 are given, first find p0 = d(x0).
- **Total sales** over the first T days at sales rate f(t) = ∫ from 0 to T of f(t) dt.
- **Total inventory carrying cost** over a period T = c1 × ∫ from 0 to T of I(x) dx, where I(x) is the inventory held at time x and c1 is the carrying (holding) cost per unit per unit of time.
- **Profitable life:** a project or machine is profitable while R'(x) > C'(x) (or plan 2's rate exceeds plan 1's). Solve R'(x) = C'(x) for the end point N; **net earnings** = ∫ from 0 to N of [R'(x) − C'(x)] dx.
- **Income stream f(t)** for T years at rate r compounded continuously:
  1. Total money flow = ∫ from 0 to T of f(t) dt
  2. Present value PV = ∫ from 0 to T of f(t) e^(−rt) dt
  3. Future value FV = ∫ from 0 to T of f(t) e^(r(T − t)) dt = e^(rT) × PV
- **Continuous annuity:** P per year paid continuously at rate j compounded continuously for n years: F = ∫ from 0 to n of P e^(jt) dt = (P/j)(e^(jn) − 1).

**Explain more**

**Surplus.**
- Demand p = 20 − x − x^2 at x0 = 3: p0 = 20 − 3 − 9 = 8. CS = ∫ from 0 to 3 of (20 − x − x^2) dx − 3 × 8 = (60 − 4.5 − 9) − 24 = 45/2.
- Demand p = 20 − 2x at x0 = 6: p0 = 8. CS = (120 − 36) − 48 = ₦36 (the triangle (1/2)(6)(20 − 8) gives the same).
- Demand p = 61 − x^2, supply p = 11 + x^2: 61 − x^2 = 11 + x^2, x0 = 5, p0 = 36, x0p0 = 180. CS = (305 − 125/3) − 180 = 250/3. PS = 180 − (55 + 125/3) = 250/3.
- Chips (q in thousands): demand p = 90 − 0.1q^2, supply p = 50 + q + 0.2q^2. 0.3q^2 + q − 40 = 0, i.e. 3q^2 + 10q − 400 = 0 = (3q + 40)(q − 10), so q0 = 10, p0 = ₦80. CS = (900 − 100/3) − 800 = 66.67 thousand naira (2 d.p.). PS = 800 − (500 + 50 + 200/3) = 183.33 thousand naira.

**Sales.**
- f(t) = 200 − 90e^(−t): ∫ from 0 to 5 = [200t + 90e^(−t)] = 1000 + 90e^(−5) − 90 = 910.61 units (2 d.p.).
- f(x) = 100 − 90e^(−x), first four days, e^(−4) = 0.018: 400 + 90(0.018) − 90 = 311.62 units (with the exact e^(−4) it is 311.65).

**Profitable life.**
- Plan 1 earns at 220 + x^2 and plan 2 at 520 + 5x naira per year. Plan 2 is better while 520 + 5x > 220 + x^2, i.e. x^2 − 5x − 300 < 0, (x − 20)(x + 15) < 0, so for **20 years**.
- A machine earns R'(x) = 14,560 − 20x^2 and costs C'(x) = 8,080 + 25x^2. Profitable while 6,480 − 45x^2 > 0, so x^2 < 144, N = 12 years. Net earnings = ∫ from 0 to 12 of (6,480 − 45x^2) dx = 77,760 − 25,920 = ₦51,840.
- Depreciation at V'(t) = 500(t − 12) naira per year: ∫ from 0 to 5 = 500[t^2/2 − 12t] = 500(12.5 − 60) = −23,750, so the loss in value is ₦23,750.

**Income streams and annuities.**
- Revenue flows into a fund at f(x) = 8,000x naira per year, 0 ≤ x ≤ 4, r = 10%.
  - Total flow = ∫ from 0 to 4 of 8000x dx = 4000(16) = ₦64,000.
  - PV = 8000 ∫ from 0 to 4 of x e^(−0.1x) dx. By parts, ∫ x e^(−0.1x) dx = −e^(−0.1x)(10x + 100). From 0 to 4: 100 − 140e^(−0.4) = 100 − 93.8448 = 6.15519. PV = 8000 × 6.15519 = ₦49,241.55.
  - FV = e^(0.4) × PV = 1.491825 × 49,241.55 = ₦73,459.76.
- ₦1,000 a year paid continuously at 10% for 6 years: F = (1000/0.1)(e^(0.6) − 1) = 10,000 × 0.822119 = ₦8,221 (nearest naira).
- Payment needed for ₦6,000 in 3 years at 6%: 6000 = (P/0.06)(e^(0.18) − 1) = P × 3.28695, so P = ₦1,825.40.
- Depletion time: use is 50 trillion cubic feet a year growing at 3% continuously, reserves 2,200. ∫ from 0 to T of 50e^(0.03t) dt = (50/0.03)(e^(0.03T) − 1) = 2,200, so e^(0.03T) = 2.32 and T = ln 2.32/0.03 = 28.05 years. (44 years, from 2,200/50, ignores the growth.)

### One-minute recap

- Integration reverses differentiation; always add c to an indefinite integral and check by differentiating.
- Power rule: x^n gives x^(n+1)/(n + 1); 1/x gives ln x; e^(mx) gives e^(mx)/m; a^x gives a^x/ln a.
- Expand products and divide quotients first; inside (ax + b), divide by a.
- f'(x)/f(x) integrates to ln f(x); f'·f^n integrates to f^(n+1)/(n + 1).
- By parts: ∫ u dv = uv − ∫ v du; take u = ln x, otherwise u = the power of x.
- Partial fractions: divide first if the fraction is improper, then cover up to find A, B.
- Definite integral = F(b) − F(a); c cancels; odd functions over [−a, a] give 0; areas between crossing curves are added as sizes.
- C = ∫ MC dx + k (C(0) = fixed cost); R = ∫ MR dx with R(0) = 0; demand p = R/x.
- CS = ∫ d(x) dx − x0p0; PS = x0p0 − ∫ s(x) dx.
- PV of a stream = ∫ f(t)e^(−rt) dt; FV = e^(rT) × PV; continuous annuity F = (P/j)(e^(jn) − 1).

### Theory practice

**Question:** A Lagos bakery's marginal cost is MC = 3x^2 − 4x + 5 naira per loaf, and its fixed cost is ₦200. Find the total cost function and the cost of producing 10 loaves.

*Answer:* C(x) = ∫ (3x^2 − 4x + 5) dx = x^3 − 2x^2 + 5x + k. At x = 0, C = k = 200 (fixed cost). So C(x) = x^3 − 2x^2 + 5x + 200. C(10) = 1000 − 200 + 50 + 200 = ₦1,050.
